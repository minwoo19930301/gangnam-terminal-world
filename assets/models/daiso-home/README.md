# 다이소 강남고속버스터미널점의 달항아리와 목제용품

2026년 4월 이 지점을 촬영한 사진에는 달항아리의 볼록한 어깨와 열린 입구, 뒤쪽의 목제 단, 조화, 펠트 받침, 흰색·검은색 압화 액자가 보인다. 목제 생활용품 코너에는 물결 테두리와 짧은 다리가 있는 소반, 포장한 컵받침, 흰 트레이에 세워 놓은 원형·사각 컵받침, 앞판에 손가락 홈이 파인 꽂이가 있다. 매장은 신반포로 194 서울고속버스터미널 지하 1층 44호다. ## Blender 편집과 게임 내보내기

[homeware.blend](homeware.blend)의 달항아리 컬렉션은 메시 361개, 나무 소반 컬렉션은 358개다. 두 컬렉션은 게임과 통합 월드의 실제 배치에 연결된다. 편집한 원본을 게임으로 내보내고 검증하려면 저장소 루트에서 다음 명령을 실행한다.

```sh
blender -b assets/models/daiso-home/homeware.blend --python-exit-code 1 -P assets/models/daiso-home/export.py
node assets/models/daiso-home/check.mjs
```

초기 원본을 다시 제작할 때는 `blender -b --python-exit-code 1 -P assets/models/daiso-home/build.py`를 실행한다. 한글 표찰을 생성할 때는 시스템 한글 글꼴을 사용하며 `GTW_KOREAN_FONT`로 경로를 지정할 수 있다. 글씨는 저장 전에 메시로 변환된다.

## 화면과 로딩

매대 앞 약 6.6m 안에서 상품이 보이면 해당 매대 하나를 상세 모델로 바꾼다. 달항아리는 149,300바이트·20,083삼각형, 목제용품은 145,128바이트·16,717삼각형이다. 뒤에서 보면 각각 2,236·852삼각형의 외곽을 사용한다. 손잡이 도마와 꽂이를 추가하면서 목제용품 파일이 8,768바이트 커졌다.

1000×640 Chromium에서 공개 통로를 걸어 각 매대 앞과 뒤, 가운데 낮은 바닥을 오갔다. 먼 곳, 뒤쪽 통로, 등을 돌린 시점의 다운로드는 0건이었다. 두 매대를 방문하고 다시 돌아올 때 각 파일은 한 번씩 읽혔다. 수정 전후 같은 여섯 시점에서 각각 72프레임을 측정했다. 화면 전체 그리기 호출은 시점당 한 번 늘었고 프레임 간격의 95백분위는 전후 모두 16.7~16.8ms였다. 통합 배치를 별도 Blender 파일에 재현한 뒤 실제 메시의 정점을 대조한 최대 월드 오차는 0.0305mm였다.
