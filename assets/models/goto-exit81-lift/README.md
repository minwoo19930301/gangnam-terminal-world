# 고투몰 8-1번 출구 보도 승강기

[게임에서 보도 입구 보기](https://minwoo19930301.github.io/gangnam-terminal-world/#/gotomall/1F?p=-84,0,-107.5,0,6) · [같은 시점 전후 비교](comparison.jpg)

2026년 1월 거리뷰에서 옅은 녹색 유리, 은색 가로·세로 프레임, 낮은 석재 받침의 줄눈과 평평한 지붕선을 확인했다. 버스 정류장 뒤쪽에서 보이는 공공 보도 입면을 모델링했다. [네이버 거리뷰](https://map.naver.com/p?p=5tmp6raeKhsEmIL5t5FlLg,-8,9,19,Float)

9호선 운영사는 역의 승강기와 점자 안내 설비를 열거한다. 이 승강기의 정확한 점자 문구, 출입면 표식, 현장 문턱 높이 및 야간 조도는 공개 자료에서 판독하기 어려웠다. 손잡이, 단순 호출판과 천장 확산광은 게임용 근사다. 지상 바닥과 문 방향은 기존 게임 배치를 따른다. [운영사 편의시설 안내](https://www.metro9.co.kr/kor/sub01_06_03.do)

Blender 원본은 `lift.blend` 안의 `GotoExit81Lift` 컬렉션이다. 원본에는 각각 편집 가능한 유리 면, 금속 마감, 석재 받침, 승객실 바닥과 천장등이 있다. `blender -b --factory-startup lift.blend -P export.py`로 금속과 마감을 한 묶음으로 내보낸다. 게임의 유리창은 한 겹으로 그린다. 승객실 표면에만 천장등 반사를 더한다. 게임 안의 실제 조명 개수는 그대로다.

정상 지도에서 ‘8-1번 출구 엘리베이터 1F’를 선택하고 같은 위치에서 네 방향을 촬영했다. 저사양 모드에서 화면 중앙 44% 사각형의 야간 밝기 중앙값(0~255)은 기존 15.5, 15.5, 15.5, 14.4에서 32.7, 32.2, 31.4, 25.7로 바뀌었다. 낮에는 120.9~141.9였다. 지상에서 상호작용 키로 B1에 내려간 뒤 다시 1F에 도착했고 양쪽 층 표시가 일치했다.
