## 편집과 배치

`gallery.blend`의 `SSG_9F_Scheherazade` 컬렉션에 개별 메시 544개와 원본에 포함한 마감 텍스처 3개가 들어 있다. 단위는 미터이며 원점은 하부장 중앙 바닥이다. Blender +X는 고객의 오른쪽, +Y는 배면, +Z는 위다. glTF Y-up 변환 후 게임 좌표 **(-51.3229, 40.6, 55.4766)** 부근에 두고 월드 +Y축으로 **110.97694°** 돌린다. 지형 모드에서는 엔진의 해당 지점 지형 높이를 더한다.

게임 자산은 **661,344바이트, 삼각형 66,085개, 드로 콜 2회**다. 간이 진열대는 1회로 묶이며 인접 시야에서 상세 모델을 불러온다. 다른 층·9층의 먼 위치·청음대 앞에서 천장을 보는 화면을 각각 새로 열었을 때 이 GLB 요청은 0건이었다. 청음대로 고개를 돌린 근거리 화면에서는 GLB 1개를 받았다.

## 다시 만들기

저장소 루트에서 실행한다. Blender 3.6.23과 내장 Bfont를 사용했다. macOS 헤드리스 환경에서는 OpenGL 백엔드로 검증했다.

```sh
D=assets/models/ssg-audio
blender -b --factory-startup --gpu-backend opengl --python-exit-code 1 -P "$D/build.py"
node "$D/pack.mjs"
node tests/smoke.mjs shinsegae
node tests/smoke.mjs gotomall shinsegae
```

수정한 Blender 원본에서 게임 모델만 다시 내보낼 때는 다음 명령을 사용한다.

```sh
blender -b --gpu-backend opengl "$D/gallery.blend" --python-exit-code 1 -P "$D/export.py"
node "$D/pack.mjs"
```
