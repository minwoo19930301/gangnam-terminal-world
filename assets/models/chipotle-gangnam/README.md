# 치폴레 강남신세계점 · 주문대

신세계 강남점 스위트 파크에 2026년 10월 28일 문을 연 지점이다. 신세계 사진에서 조명 아치 아래 붉은 고추 엠블럼과 흰 글자, 가로형 메뉴 화면을 확인할 수 있다. 운영사가 제공한 두 번째 사진은 스테인리스 주문대, 재료를 고르는 줄, 계산 단말기와 겹쳐 놓은 크라프트 봉투를 보여 준다. 메뉴에는 볼·부리토·타코·샐러드와 고기, 살사, 과카몰레가 보인다. [신세계그룹 뉴스룸](https://www.shinsegaegroupnewsroom.com/chipotle-opens-its-first-store-in-a-distribution-facility/) · [상미당홀딩스 제공 현장 사진](https://www.ekn.kr/web/view.php?key=20261030022163589)

11월 25일 강남점 B1 안내도에서 치폴레 이름이 두 셀에 걸쳐 있다. 게임에서는 동쪽 셀에 사진의 주문대를 한 번 배치하고, 맞은편 셀에는 테이블을 두었다. 운영사 발표는 매장 전체 98석을 확인한다. 개별 테이블 위치, 개수, 주문대 치수와 방향은 게임 통로에 맞춘 근사치다. [강남점 B1 도면](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png)

Blender에서 `counter.blend`의 `ChipotleGangnamOrderBar`를 편집한다. 이 디렉터리에서 `blender -b counter.blend -P export.py`를 실행하면 게임용 단일 표면을 내보낸다. 13m 이내에서 현재 층과 카메라에 보일 때 불러오며 복귀용 거리는 16m다. [게임 전후 및 밤 근접 화면](comparison.jpg)
