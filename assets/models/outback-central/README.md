# 아웃백스테이크하우스 센트럴시티점

파미에에서 호남선 하차장 쪽으로 걸으면 1층 기둥의 흰 **OUTBACK · M층** 안내를 볼 수 있다. 매장은 중층에 있다. 파미에 실내 거리에서 위층 난간을 올려다보면 붉은 입체 상호가 보이고, 중층 매장 문을 통과하면 목재 접수 바와 대기 벤치가 나온다. 지도 검색어는 ‘아웃백’ 또는 ‘OUTBACK STEAKHOUSE’다.

[같은 게임 시점에서 본 변경 전후](approach.jpg). 왼쪽이 이전, 오른쪽이 변경 후다. 위에서부터 호남선 하차장 쪽으로 걷는 시선, 1층 회랑에서 올려다본 중층 간판, 접수 바를 바라보는 매장 입구다.

## 지점과 사진

- 운영사 중층도에는 아웃백의 긴 구획과 딤딤섬 사이에 수직 이동 표시가 있다. 네이버 지점은 서울 서초구 신반포로 176, M1층으로 안내한다. 지점 대표핀을 게임에 투영한 위치는 월드 약 (−93.90, 204.66), 터미널 로컬 (196.62, −31.94)로 기존 아웃백 구획 안이다. 고객 출입문·간판 위치와 폭은 게임의 유리 입면과 복도에 맞춰 추정했다. [센트럴시티 중층도](https://www.shinsegaecentral.com/public/20211116/M1F.png) · [1층 안내도](https://www.shinsegaecentral.com/public/img/famille_floor_1_ko_map.png) · [네이버 지점](https://map.naver.com/p/entry/place/1246036062)
- 2022년 7월 방문자가 찍은 사진에는 호남선 쪽 공용 기둥의 검은 안내띠, 1층에서 보이는 상부 적색 간판, 에스컬레이터 옆 벽돌 벽의 층별 안내가 담겨 있다. 1층 손님에게 보이는 상호와 중층 문 앞의 흰색 접수대 상호를 각각 만들었다. 검은 띠의 한글 층 안내와 다리 난간의 방향 안내는 게임에서 읽을 수 있게 구성했다. [방문자의 접근 사진](https://joeunlife82.tistory.com/91)
- 운영사 지점 사진과 2020년 3월 방문 사진에서 흑색 캐노피, 밝은 능선 윤곽과 흰 OUTBACK 글자, 나무 상판과 후면 판재, 대기용 단말, 검은 긴 벤치를 확인했다. 상품 가격과 행사 문구는 모델에 넣지 않았다. 입체 문자는 브랜드 웹사이트의 상호 외곽선을 사용했다. [운영사 지점 사진](https://www.shinsegaecentral.com/famille/OutbackSteakhouse) · [접수 바와 대기 단말 사진](https://joointhe.tistory.com/62) · [브랜드 상호 원본](https://www.outback.co.kr/asset/images/common/logo_red_type_02.png)

## 실제 게임 보행

헤드리스 Chromium의 일반 플레이에서 호남선 승차장 쪽 카페 앞 보도를 출발해 W로 약 51m 걸어 하차장에 도착했다. 하차장에서 기존 파미에 엘리베이터까지 약 36m를 걸은 뒤 E와 2F 버튼을 눌렀다. 상단은 게임 높이 5m의 **파미에스테이션 엘리베이터 홀 · 2F**다. 기존 2층 공용 다리와 중층 회랑을 따라 약 114m, 문 안으로 약 2.4m를 더 걸으면 **아웃백스테이크하우스 센트럴시티점 · 1M**이 표시된다. 같은 승강기의 1F 버튼으로 하차장에 돌아올 수 있다. 이 거리는 게임에서 걸은 거리다. 방문 사진에 보이는 에스컬레이터의 정확한 1층·중층 대응 위치는 두 개의 도식에서 추정 범위가 넓다.

뉴코아 5층에서 일반 M 검색으로도 중층 입구에 도착했다. ‘아웃백’ 결과는 1건이며, 5초간 서 있는 동안 높이 5m와 위치를 유지했다. 최초 접근에서 1층 하차장 기둥은 상세 모델 요청 0회, 열린 회랑에서 올려다본 적색 간판은 간판 파일 1회, 중층 입구에서 접수 바를 보면 접수 파일 1회였다. 같은 중층 입구에서 매장과 간판을 등지고 시작했을 때 두 파일 모두 요청 0회였다.

## 편집과 확인

[front.blend](front.blend)의 `OutbackCentralGallery`와 `OutbackCentralReception` 컬렉션을 편집한다. 글자는 조정할 수 있는 곡선이고, 캐노피·판재·카운터·벤치는 개별 메시다. 월드 배치는 `assets/models/world/indoor-layout.mjs`가 실제 게임의 회전과 좌표에서 읽는다. 웹용 간판은 29,672바이트·3,428삼각형, 접수 바는 36,960바이트·3,900삼각형이다. 각각 한 개의 드로를 사용한다.

```sh
blender -b assets/models/outback-central/front.blend -t 4 --python-exit-code 1 -P assets/models/outback-central/export.py
node assets/models/outback-central/check.mjs
```
