# 파미에스테이션 1층 젤라띠젤라띠

신세계 센트럴의 1층 도면은 젤라띠젤라띠를 22번으로 표시한다. 지점 사진에서 회랑을 향해 열린 주문대, 가운데 콘을 둔 청록색 입체 간판, 구형 조명, 흰 맛 표찰을 단 메뉴판, 나무장에 겹쳐 세운 와플콘을 확인했다. 주문대의 금속 뚜껑은 닫혀 있고 바로 앞에 작은 맛 표지가 있다. 젤라또의 색은 손님에게 건넬 컵과 콘, 젤라또라떼 위에서 볼 수 있다. [신세계 센트럴 지점 안내와 사진](https://www.shinsegaecentral.com/famille/GelatiGelati) · [공식 1층 도면](https://www.shinsegaecentral.com/public/img/famille_floor_1_ko_map.png) · [네이버 지도 지점](https://map.naver.com/p/entry/place/36324317) · [2025년 지점 사진](https://mydon-mysan.tistory.com/114) · [지점의 컵과 주문대](https://limefood.tistory.com/62)

게임에서는 기존 녹색 가구를 지점 전용 주문대와 장으로 교체했다. 회랑에서 매장 앞으로 들어가 금속 난간을 따라 좌우로 걸을 수 있다. 매장 폭 7.42m와 깊이 5.03m는 게임 도면에 맞춘 값이다. 흰 메뉴판의 맛 조합과 배열, 콘과 종이컵 수량, 손님에게 건네는 상품 위치는 사진에 보이는 범위에서 구성했다. [게임 화면의 같은 자리 전후 비교](play.jpg)

## 원본과 내보내기

`gelateria.blend`에는 집기·상품을 편집할 수 있는 메시 1,436개가 있고, 게임에 들어가는 부분을 11개 컬렉션으로 묶었다. 접시처럼 둥근 통 뚜껑에는 간접 반사를 정점 색으로 저장했다. 간판과 구형 조명은 실내에서 자체 발광하며 보호유리는 네 장이다. 통합 Blender 장면은 컬렉션을 원본에 상대 연결한다.

저장소 루트에서 편집한 상품과 위치를 웹에 내보내고 보행 검사를 실행한다.

```sh
blender -b assets/models/gelati/gelateria.blend --python-exit-code 1 -P assets/models/gelati/export.py
node assets/models/gelati/check.mjs
```

원본의 초기 형태를 다시 생성할 때는 아래 명령을 실행한다.

```sh
blender -b --python-exit-code 1 -P assets/models/gelati/build.py
```

열 개의 GLB를 모두 합치면 590,592바이트다. 회랑에서는 간판이 먼저 보이고 손님용 컵은 3.9m 안에서 보일 때 상세 모델을 읽는다. 콘 장의 100묶음은 같은 기본형을 사용한다. 게임은 6,276바이트인 원형과 배치를 읽고 한 번에 그린다. Blender에서 한 묶음을 회전하거나 늘여도 배치에 반영된다. 메시 하나를 독립 편집하거나 구성품을 바꾸면 내보내기가 자동으로 장 전체의 형상을 굽는다.

## 게임 검증

같은 PC에서 바꾸기 전후의 아홉 시점을 각각 72프레임 측정했다. 공개 회랑과 주문대를 걸을 때 위치와 바닥 높이가 일치했다. 프레임 간격 95백분위는 전후 모두 16.7~16.8ms였고, 카메라에 따라 화면 전체의 그리기 호출은 4~6회 늘었다. 상품 전체가 보이는 시점은 최대 83,205삼각형 늘었다. 멀리 있거나 등을 돌리거나 옆 가게에서 가림벽을 볼 때 이 점포의 GLB 요청은 0회였다. 회랑에서 주문대를 따라 움직이고 다시 들어갔을 때 각 파일을 한 번씩 받았다. 별도 Blender 검증 장면에서 11개 배치와 게임 좌표의 최대 차이는 0.0341mm였다.
