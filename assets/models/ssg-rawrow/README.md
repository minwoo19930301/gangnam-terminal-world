# 신세계 강남점 8층 로우로우

로우로우의 직영점 안내에는 신세계백화점 강남점 본관 8층과 지점별 매장 사진이 함께 실려 있다. 신세계의 현재 8층 도면에 있는 로우로우 점포 안에 사진의 금속 선반, 파스텔 트렁크, 걸린 가방, 흰 루버 수납장과 주홍색 R 표찰을 재현했다. 게임의 점포 폭이 약 2m라서 사진에서 보이는 전체 매장 중 양쪽 진열대 한 구간을 골랐다. 진열 수량과 간격은 축약했다. 기존 스포츠 매대 대신 하나의 편집 가능한 컬렉션을 사용한다. 바퀴, 잠금쇠, 손잡이, 가방 몸체와 선반을 개별 부품으로 만들었다. 가까이에서 보이는 GLB는 89,472바이트이며 상점 하나에 드로 호출 한 번을 사용한다. 8층 기본 도착점과 매장을 등진 통로에서는 이 파일을 요청하지 않았다. 실제 게임에서 저사양 설정으로 같은 카메라의 주간·야간 화면을 비교했다.
