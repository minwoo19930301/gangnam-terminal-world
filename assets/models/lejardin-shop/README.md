# 르자당 센트럴시티점

신반포로 176 센트럴시티 1층 122-1호 꽃집이다. 지점은 내려가는 에스컬레이터와 쉐이크쉑 근처로 안내한다. 11월 6일 방문기의 광장 시점과 네이버 지점 사진에 보이는 흰 입체 세리프 간판, 홈을 낸 석재 기둥, 목재 폴딩 도어, 검은 3단 절화 냉장고, 창 앞 조명 트리 세 그루와 붉은 선물을 만들었다. 카드대와 간접 조명이 들어간 손질대도 지점 사진을 참고했다. [네이버 지도](https://map.naver.com/p/entry/place/1654024884) · [지점 사진](https://pcmap.place.naver.com/place/1654024884/photo) · [11월 현장 촬영](https://m.blog.naver.com/mattias7/224466753309)

꽃다발은 두 종류다. 아이보리 포장에는 푸른 수국과 보라색 리시안셔스를 넣었고, 크라프트 포장에는 노란 거베라와 분홍 국화, 안스리움을 섞었다. 게임 속 꽃 종류와 송이 수, 냉장고와 진열대 치수는 사진을 보고 재구성했다. 원점은 기존 오픈 스테이지 앞 점포를 따랐다. 게임 좌표로 환산한 네이버 핀은 매장 앞 중앙에서 약 5.7m 떨어져 있다. [네이버 지점 사진](https://pcmap.place.naver.com/place/1654024884/photo)

뉴코아를 비롯한 다른 실내에서도 지도에서 ‘르자당’, ‘Le Jardin’ 또는 ‘122-1호’를 검색하면 매장 입구를 선택할 수 있다. 직접 주소는 `#/centralcity/1F?destination=lejardin`이다. 통로에 도착하면 정면에 흰 LEJARDIN 간판과 절화 냉장고가 보인다.

[게임 전후·야간](play.jpg) · [Blender 근접 렌더](studio.jpg) · [편집 원본](flowershop.blend)

Blender 원본에는 18개 컬렉션, 편집 메시 오브젝트 2,404개가 있다. 11종의 꽃잎과 침엽 가지를 직접 만들고, 825개의 꽃송이와 가지에 원형을 재사용했다. 게임은 정면·경사·측면에서 촬영한 꽃의 모습 중 줄기 각도에 맞는 것을 고른다. 약 1m 앞에 와서 꽃을 볼 때 해당 품종의 메시를 한 번 받고 보이는 송이에만 그린다. 전나무는 원본의 개별 침엽을 두 방향에서 촬영해 가지 실루엣으로 바꿨다. 전구 2,593개는 점으로 그리고 깊이 검사를 적용해 잎과 매장 벽 사이에서 가려진다.

세로 홈의 석재·목재 전면, 타일, 냉장고, 카드대, 포장과 주문대의 표면과 조명을 Cycles로 구웠다. 냉장고의 철제 프레임과 안쪽 반사판은 광택이 다르다. 유리의 반사에는 게임 속 매장을 여섯 방향으로 촬영한 이미지를 썼다.

```sh
blender -b assets/models/lejardin-shop/flowershop.blend --python-exit-code 1 -P assets/models/lejardin-shop/export.py
node assets/models/lejardin-shop/capture-reflection.mjs
node assets/models/lejardin-shop/check.mjs
node tests/open-stage.mjs --gpu
```

일반 키보드 보행으로 광장에서 매장 안 손질대까지 8.26m를 걸었다. 중층과 매장의 옆벽·뒷벽 너머, 광장에서 등진 시점의 상세 요청은 각각 0건이었다. 냉장고, 주문대, 트리, 폴딩 도어의 충돌과 입구·통로의 여유 공간도 검사했다. 오픈 스테이지와 호남선 대합실 사이 두 통로를 양방향으로 걸었다.
