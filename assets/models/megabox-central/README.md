# 메가박스 센트럴 · B1 매표 로비

기존 게임에서는 백화점 B1 평면도의 영화관 셀이 건물 경계에서 잘렸다. 백화점 쪽 입구 위치에 서면 센트럴시티 지하 연결통로로 표시되고 매표 로비나 상호가 보이지 않았다. 같은 시점에서 백화점과 센트럴시티 양쪽 게임 페이지 모두 흰색 MEGABOX 입체 문자와 안쪽 카운터가 보이도록 했다. [낮과 밤 세 시점 비교](comparison.jpg) · [일반 게임 카메라](camera.json)

메가박스 센트럴 지점 안내는 매표소·매점·무인발권기를 지하 1층에, 카페·라운지를 중층에 표시한다. 신세계백화점 강남점 B1 고객용 도면에서 영화관과 광장이 만나는 직선 구간에 백화점 쪽 입구를 맞췄다. 2023년 방문자가 촬영한 같은 지점의 사진에는 석재 마감, 반원 유리와 어두운 문틀, 흰 MEGABOX 글자가 보인다. 별도의 정면 출입구와 달리 이쪽 사진의 바닥은 문 안까지 평평하다. 도면이 문 중심이나 창 너비를 실측치로 제공하지 않아 두 치수는 사진과 기존 게임 축척에 맞췄다. 공개 카운터 사진에 보이는 청색 메뉴판, 짙은 목재 패널, 황금색 안면의 펜던트와 ‘Speed Order’ 주문기 두 대를 반영했다. 메뉴 그림은 새로 그렸으며 수시로 바뀌는 품목과 가격은 생략했다. 편집용 컬렉션은 [entrance.blend](entrance.blend)의 MegaboxBoutiquePublicFront다.

새 캐시로 방문했을 때 정면·사선·로비 안에서는 각각 96,832바이트 GLB를 한 번 요청했다. 정면과 같은 자리에 서서 반대로 보거나 먼 식품관에 서면 요청은 0회였다. 상세 모델은 화면에 보일 때 23m 안에서 켜지고 26m 밖에서는 단순 모델로 돌아간다. 센트럴시티 페이지에서도 같은 카메라에서 로고가 보였고 상세 파일은 한 번만 내려왔다.

760×480 헤드리스 Chromium에서 입구 밖부터 카운터를 향해 8.6m 걸었다. 저사양 두 번의 보행 p95는 20.4~20.8ms, 일반 모드 두 번은 20.9~21.3ms였다. 네 번 모두 도착 높이와 표시 층이 B1으로 유지됐다. 완성된 백화점 페이지의 고정 시점 드로 호출은 정면 47~50회, 사선 148~151회, 안쪽 40~43회였다. 변경 전 비교 화면은 기존 주소가 안정되는 센트럴시티 페이지에서 같은 좌표와 방향으로 촬영했다.

11월 25일 B1 안내도에서 보앤미와 마켓 사이의 흰 통로는 카페 앞 갈림길을 지나 영화관 원형 광장까지 이어진다. 두 건물의 지상 경계를 지하에도 적용하던 벽을 통로 폭만큼 열었다. 사선 통로를 가로지르던 중복 에스컬레이터는 기존에 추정한 위치였다. 호남선 1층 안내도와 백화점 B1 안내도를 대조해 해당 시설과 바닥 구멍을 함께 정리했다. 게임 기본 B1 입구에서 보앤미 옆으로 걸어 카페 통로와 영화관 매표 로비에 각각 도착했다. 임대 매장 앞쪽의 회벽과 바닥색은 게임의 인접 마감을 이은 근사치다.
