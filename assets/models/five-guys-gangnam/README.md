# 파이브가이즈 고속터미널점 · 주문과 음료대

에프지코리아가 2024년 2월 공개한 지점 사진에는 검은 FIVE GUYS 입구 두 개, 목재 아치형 MILK SHAKES 창, 검은 차양, 빨간 펜던트와 음료대가 함께 보인다. 방문자가 찍은 같은 지점의 사진에서 음료기 옆 붉은 주문대, 밝은 메뉴판, 은박 포장에 담긴 참깨번 버거와 흰 음료 컵을 확인했다. [한화갤러리아의 개점 사진](https://www.hanwhagalleria.co.kr/promotion/news/id/839ddb4c-63ba-4a89-9e41-05cb6d50e52d?p=0) · [고속터미널점 방문 사진](https://bomb8426.tistory.com/41)

11월 25일 도면이 표시한 두 셀을 이용해 주문대와 음료 설비를 한 세트로 묶었다. 게임 서쪽 입구에는 사진에 나온 포털과 주문대를, 다른 셀에는 별도의 입구와 좌석을 두었다. 지점 사진은 두 입구의 존재와 내부 구성을 확인해 주며, 각 집기의 정확한 평면 좌표와 크기는 추정이다. [강남점 B1 도면](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png)

`front.blend`의 `FiveGuysGangnamFront` 컬렉션을 편집하고 이 디렉터리에서 `blender -b front.blend -P export.py`로 게임용 단일 표면을 내보낸다. 포일과 버거도 각각 편집할 수 있다. 13m 안에서 현재 층과 시야를 검사해 상세를 읽는다. [게임 전후 및 밤 근접 화면](comparison.jpg)
