# 신세계 강남점 신관 8층 살로몬

살로몬의 강남점 리뉴얼 사진에는 옅은 타일 바닥, 얇은 곡선 간접등, 밝은 벽면의 작은 워드마크, 금속 신발 선반과 나무 벤치가 보인다. 게임에서는 8층 점포 도면에 등록된 살로몬 바닥에만 이 마감을 적용했다. 타일 크기와 줄눈, 천장 곡률, 진열 상품 수와 배치는 게임 공간에 맞춰 잡았다. [살로몬코리아 리뉴얼 안내](https://salomon.co.kr/pages/salomon_gangnam_renewal_open)

곡면 조명과 간판의 밝은 면은 한 개의 정적 발광 메시로 묶었다. 선반·벤치·상품은 미터 단위로 편집할 수 있다. [블렌더 원본](gallery.blend) · [일반 게임에서 매장 보기](https://minwoo19930301.github.io/gangnam-terminal-world/#/shinsegae/8F?p=-59.595,35.82,76.056,103.428) · [주간 플레이 화면](interior.jpg)

러닝화 끈과 밑창 돌기의 작은 단면을 다듬어 상품 메시를 51,786개에서 41,274개 삼각형으로 줄였다. 천장과 간판을 포함한 전체 게임 파일은 693,308바이트다. 일반 플레이 화면 네 곳을 같은 낮 조명으로 비교한 결과 RGB 채널 중 하나라도 8/255를 넘게 바뀐 픽셀은 각 화면의 0.21% 이하였다. 매대를 등지거나 같은 위치의 7층에 있을 때 상세 파일 요청은 0건, 8층에서 돌아서서 접근한 뒤에는 누적 1건이었다.
