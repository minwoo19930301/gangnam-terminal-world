# 고속터미널 중앙정류소 22-019 · 22-020

두 승차섬에 검은 금속 차양, 강화유리, 목재 벤치와 전광판을 배치했다. 안내판에는 정류소 번호와 서울 시각이 표시된다. 지도에서 정류소 번호를 선택하면 해당 승차섬의 보행 공간으로 이동한다. [같은 위치에서 본 변경 전(왼쪽)과 후(오른쪽)](shelters.jpg)

## 모양과 위치

네이버의 2026년 1월 거리뷰로 기둥·광고면·뒤쪽 난간·포장의 배치를 확인했다. 매체사가 공개한 22-020 차도 방향 여섯 면과 매체 규격 1.2 × 1.8 m를 기준으로 케이스를 만들었다. 뒷유리의 반투명 띠 사이로 차도와 맞은편 건물이 보인다. 광고 속 반포 달빛무지개분수와 서래섬 유채꽃은 Blender로 제작한 원화이며, 특정 시점의 집행 광고를 재현한 그림이 아니다. [네이버 거리뷰](https://map.naver.com/p?p=lHsXW6lxT97x-yAj0PFdXA,0,0,80,Float) · [22-020 도로면 매체 사진과 규격](https://tkad.co.kr/ko/media/express-bus-terminal-central-shelter-ad-roadside-face-22-020) · [반대편 정류소 매체 사진](https://www.houseofooh.com/media/36931)

서울시 자료의 2026년 11월 2일 기준 정류소 대표점과 게임 내 승차섬 중심 사이 거리는 22-019에서 13.3 m, 22-020에서 18.8 m다. 지붕과 플랫폼의 위치·높이는 도로 메시와 사진에 맞춰 추정했다. 현장 실측값은 확보하지 못했다. [서울시 정류소 위치정보](https://data.seoul.go.kr/dataList/OA-21288/S/1/datasetView.do) · [좌표 기록](../../../data/research/streets.json)

## 원본과 게임

[shelters.blend](shelters.blend)에는 차양과 벤치 부품 237개, 광고 원화 두 장, 전광판 부품 26개가 있다. 한 차양에 달린 선형 LED 여섯 개와 광고 케이스 광원 네 개로 보도·차도에 닿는 빛과 벤치 다리 그림자를 Cycles에서 구웠다. 서울 태양 고도에 맞춰 날이 어두워지면서 등과 포스터가 밝아진다. 낮에는 포장 조명 파일을 요청하지 않는다.

거리에서는 간단한 메시를 보여 주고 유리·포스터는 25 m, 차양은 18 m, 전광판은 12 m 이내의 시야에서 상세 파일을 처음 요청한다. 같은 파일을 두 승차섬에서 공유한다. 차양 상단의 글자는 Blender 원본에 개별 글자로 남기고 게임에서는 1,536픽셀 표면에 합쳤다. 근경 차양은 15,104삼각형이다.

```sh
blender -b --factory-startup -P assets/models/sinbanpo-bus-shelters/build.py
node assets/models/sinbanpo-bus-shelters/check.mjs
```

검사는 승차섬 안쪽 11 m 실제 보행, 두 승차섬 재방문, 조회한 파일 수, 보행 중 구역 재로딩 여부와 낮·일몰·밤·일출의 밝기를 확인한다.
