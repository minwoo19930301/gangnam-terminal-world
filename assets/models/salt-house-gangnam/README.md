# 소금집 샌드위치 강남점

운영사의 지점 안내는 신세계백화점 강남점 B1을 명시한다. 2025년 8월 15일 방문자가 직접 찍은 사진 여섯 장에서 검은 목재 입구, 황동 테두리 안의 ‘SALT HOUSE SANDWICH’, 왼쪽 주문대, 안쪽 음료 냉장고와 밝은 세 칸의 숙성 진열장, 오른쪽 식탁을 확인했다. 11월 25일 백화점 B1 안내도에서 소금집은 인텔리젠시아와 네스프레소 사이에 있다. [운영사 지점 안내](https://www.salthouse-sandwich.com/store) · [강남점 정면·주문대·숙성장·식사 사진](https://minyeo-muse.tistory.com/entry/신세계백화점-강남점소금집🥪-방문기)

모델에는 사진 속 종이 포장 샌드위치와 빨간 육절기, 잠봉 뵈르·프로마쥬 메뉴, 매달린 장육과 고리 모양 소시지, 나무 받침에 놓인 뼈 붙은 햄이 있다. 식탁에는 분홍색 인쇄지 위의 바게트, 금속 접시와 당근 라페, 오렌지 주스를 놓았다. 제품 그림과 재료 질감은 직접 만들었다. 4면의 범위는 백화점 B1 도면에 따랐고, 진열장 간격과 가구 크기는 사진을 게임에 맞춘 근사값이다. [보행자 시점 전후 비교](comparison.jpg)

Blender 원본의 `SaltHouseGangnam` 컬렉션에서 입면, 메뉴, 음식, 숙성장과 집기를 따로 편집할 수 있다. 원본에 인쇄·목재·육가공품 표면 이미지가 내장돼 있다. 수정한 원본은 두 번째 명령으로 내보낸다.

```sh
blender -b -P assets/models/salt-house-gangnam/build.py
blender -b assets/models/salt-house-gangnam/shop.blend -P assets/models/salt-house-gangnam/export.py
```

매장 앞 주소는 `#/shinsegae/B1?p=-84.17607,-6,53.06413,126.25469,6`이다. 게임 지도에서 ‘소금집’을 고르면 열린 입구로 들어선다. 정상 키보드 보행으로 카페 통로에서 주문대와 숙성장을 거쳐 19.2m를 왕복했고 y=-6을 유지했다. GLB 하나에 인쇄 이미지를 포함한 297,796바이트이며 19,162개 삼각형을 한 번에 그린다. 입구·주문대·식탁·숙성장은 각각 1회 요청했고 반대 방향, 18m 밖, 인접 인텔리젠시아 내부와 신세계 8층은 0회였다. 두 구역 smoke, native 배치 1개, 편집 원본의 반복 수출 SHA-256 일치를 확인했다.
