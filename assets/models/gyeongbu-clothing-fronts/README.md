# 경부선 의류도매상가 7·8층

층 입구에서 중앙 통로로 들어가면 같은 모양의 옷걸이가 보이던 두 매장을 층별 공개 사진에 맞춰 바꿨다. 7층은 회색·감색 옷을 두 단에 건 양복 매장으로, 앞에는 코트와 셔츠·넥타이를 입힌 마네킹 두 점을 세웠다. 8층은 꽃무늬 블라우스와 니트, 스카프, 집게에 걸린 긴 바지를 높이별로 나눠 볼 수 있다. 매장 표찰에는 사진에서 읽기 어려운 상호 대신 상품 종류를 적었다. 매장 폭 약 5.1m와 배치는 기존 게임의 점포 칸을 따랐다.

운영사 안내에는 6~8층이 의류, 9층이 고속버스회사 사무실, 10층이 음식점 두 곳과 성당으로 나온다. 6층의 기존 아동복 매장과 7·8층 중앙의 기존 매장은 그대로 이용할 수 있다. 9층은 층 도착 표시와 승강기 안내에 사무층 용도를 표시한다. 운영사가 지금 제공하는 사진에는 촬영일이 적혀 있지 않으므로 현재 개별 점포의 호수, 상호, 입점 여부는 확인할 수 없다. 두 매장은 각각 별도의 Blender 컬렉션이다. 화면에 들어올 때 저해상도 형태를 먼저 읽고, 가까이에서는 옷감 텍스처를 공유하는 매장 메시 하나를 그린다. 7층의 근거리 GLB는 214,772바이트, 8층은 349,284바이트다. 새 브라우저에서 같은 층 입구에 서서 반대로 보면 두 매장 모두 프록시와 GLB 요청이 0건이었다. 매장을 향하면 해당 층 파일 두 개만 요청했다.
