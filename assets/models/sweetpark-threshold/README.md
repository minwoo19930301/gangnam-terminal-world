# 스위트 파크 카페 통로 입구

신세계 강남점 B1에서 오설록과 네스프레소 사이를 지나 스위트 파크로 들어가며 보는 목재 입구다. 제작사 RMS는 신세계 의뢰로 2024년 2월 작업한 간판을 공개했다. 사진에서 오설록은 왼쪽, 네스프레소는 오른쪽에 보이고, 두 가게 사이 인방의 중앙에 SWEET PARK가 적혀 있다. 은빛 옆창, 층진 미색 천장과 격자 조명, 밝은 줄눈과 짙은 교차점이 있는 대리석 바닥을 같은 시야에 맞췄다. [RMS 프로젝트 35](https://www.retailmedia.co.kr/pages/work/detail.html#p35) · [제작사 현장 사진](https://www.retailmedia.co.kr/upload/2025083115363166a8d9b8efa242a7b43b10b8e48896df.jpg)

2026년 11월 25일자 공식 층별도에서 두 가게는 마주 본다. 이 상대 배치와 사진의 원근을 기준으로 기존 통로 안에 맞췄다. 인방의 종방향 위치와 치수, 대리석 무늬, 천장 패널 개수는 게임 축척에 따른 근사값이다. 기존 벽·바닥 충돌을 그대로 사용한다. [신세계 강남점 B1 공식 층별도](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png)

## 게임과 Blender

게임 주소는 `#/shinsegae/B1?p=-81.58634,-6,58.81443,-144.17878`이다. [낮·밤 동일 시점 비교](comparison.jpg)

`threshold.blend`의 `SweetParkCoffeeThreshold` 컬렉션에 글자 곡선, 유리창, 목공, 대리석 인레이와 확산 조명이 있다. Blender의 로컬 −Y가 손님 방향이다. 곡선과 마감은 원본에서 직접 편집한 뒤 폴더 안에서 아래처럼 내보낼 수 있다. 초기 서체 윤곽은 제작사 사진에서 직접 그린 11개의 닫힌 선이다.

```sh
blender -b threshold.blend -t 4 -P export.py
```

`build.py`는 기본 설계로 원본을 재생성한다. 웹 상세에는 정점색 재질 한 개와 드로 한 개를 사용한다. 원거리·다운로드 대기 중에는 간판 윤곽과 통로의 바닥·천장 패턴을 단순화한 대체 모델이 먼저 보인다. 근거리 정면에 상세 모델을 한 번 요청한다.
