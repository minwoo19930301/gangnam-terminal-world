# 파미에스테이션 1층 와라쿠샤샤

네이버 지도는 서울 서초구 신반포로 176 파미에스테이션 1층 114호로 안내한다. 신세계 센트럴의 1층 안내 번호는 27번이다. 지점 전면 사진에서 흰 붓글씨와 붉은 낙관, 낮은 목재 창살, 검은 문발, 회랑 오른쪽의 음식 견본장과 독립 메뉴대를 확인했다. 실내 사진에는 같은 식탁의 두 개별 인덕션, 벽 쪽 회색 줄무늬 벤치, 맞은편 의자, 짙은 벽 타일과 간접 조명이 보인다. 게임에서는 공개 전면, 견본장과 맨 앞 식탁 한 개의 두 자리를 만들었다. 검은 냄비 안에 배추·두부·버섯·돌돌 만 쇠고기를 따로 만들고 대나무 발에 담긴 우동, 추가 쇠고기, 계란·소스·절임 접시와 국물병을 놓았다. 맞은편에는 새우 두 마리와 가는 면이 담긴 에비텐 우동을 뒀다. 현관 견본장은 실물 사진을 참고해 축소 그릇과 상표를 구성했다. 게임의 전면 4.36m, 깊이 2.76m와 가구의 위치·치수, 주문 구성, 견본 수량, 조명 출력은 추정값이다. 우측 1게이트의 기존 벽돌 기둥 안쪽에 매장의 마감을 맞췄다. ## Blender와 게임

`dining.blend`의 개별 컬렉션에서 집기와 상품을 편집할 수 있다. 별도 장면 ‘114호 · 조명과 앞쪽 두 자리’에는 실제 게임 위치 관계로 놓인 13개 컬렉션 인스턴스와 여덟 영역광이 있다. 1,017개 메시와 조명 모두 파일 안에 저장된다. 실내 마감과 식탁에는 Cycles의 직접광·간접광을 계산해 서로 다른 조사량 지도를 쓴다. 게임에서는 지도의 0.5를 중립으로 놓고 기존 실내 조명에 곱한다. 따라서 낮과 밤의 밝기, 처마 아래·식탁 밑 그림자, 물건 간의 차폐를 함께 반영한다. 간판과 조명 개구부의 발광은 따로 처리한다. [같은 시점의 낮과 밤](lighting.jpg)

저장소 루트에서 편집 결과를 내보내고 정상 진입 경로로 검증한다.

```sh
blender -t 3 -b assets/models/waraku/dining.blend --python-exit-code 1 -P assets/models/waraku/export.py
node assets/models/waraku/check.mjs
```

초기 형태를 다시 생성할 때는 아래 명령을 실행한다.

```sh
blender -b --python-exit-code 1 -P assets/models/waraku/build.py
```

12개 GLB의 합은 547,904바이트와 60,825삼각형이다. 세 장의 유리는 6삼각형이고, 두 광원 지도의 합은 50,494바이트다. 먼 회랑에서는 간판과 입구가 먼저 보인다. 음식은 입구나 통창 안쪽으로 시야가 통하고 약 3.7m 이내에 접근하면 읽는다. 뒤쪽 벽, 옆 게이트 기둥 뒤, 회랑에서 돌아섰을 때의 독립 테스트에서 받은 매장 모델과 광원 지도는 0건이었다. 회랑에서 들어와 식탁과 진열장을 둘러보고 재진입할 때 각 파일을 한 번씩 받았고, 다 받은 뒤에도 뒤쪽의 불투명한 벽에서 열한 묶음이 숨겨졌다.

실제 게임을 1000 × 640으로 실행해 전후 같은 좌표·방향, 같은 바닥에서 11곳을 각각 72프레임 측정했다. 이 기기의 프레임 간격 95백분위는 전후 모두 16.7~16.8ms였다. 전체 화면의 그리기 호출은 시점별로 2~11회, 삼각형은 19,977~43,154개 늘었다. 식당 앞, 실내 통로와 식탁 가장자리, 견본장 앞 충돌을 확인했다. 옆 1게이트는 전후 같은 중심선을 따라 양방향으로 걸어 바닥 높이 0m를 유지했다. 별도 Blender 검증 장면에서 13개 배치와 게임 좌표의 최대 차이는 0.0315mm였다.
