# 경부선 3층 생화상가 · 절지와 열매 진열대

서울고속버스터미널의 본관 3층 안내 사진을 보면, 녹색 바닥 옆 매대에서 절지 묶음이 여러 높이로 겹쳐 선반 가장자리까지 덮고 있다. 연두 열매를 단 가지, 길게 늘어진 붉은 꽃차례, 흰 꽃대, 보라색 잔꽃과 둥근 은녹색 잎이 보인다. 운영사는 이 층을 생화와 조화로 구분해 안내한다. 안내 페이지에는 촬영일이 없고 사진에서 매장 이름이나 호수를 읽을 수 없어 게임의 기존 생화 구역에서 상호 없는 매대 한 면을 골랐다. 폭 3.8m와 선반 높이는 그 매대에 맞춘 값이다. [운영사 층별 안내](https://www.exterminal.co.kr/floor.asp) · [운영사가 게시한 3층 매장 사진](https://www.exterminal.co.kr/images/floor03.jpg)

기존 화면에서는 이 매대에도 주변과 같은 꽃통과 둥근 꽃송이가 줄지어 있었다. 교체한 면에서는 손님 쪽으로 눕힌 가지, 앞으로 처진 잎과 열매, 나뭇결 색 선반 턱과 집게 표찰을 볼 수 있다. [세 시점의 일반 플레이 변경 전후](comparison.jpg) · [낮·밤 카메라 주소](camera.json)

[편집용 Blender 파일](flower-bank.blend)에는 3단 선반과 표찰, 다섯 가지 식물 묶음이 들어 있다. 18묶음은 방향과 크기를 조금씩 달리해 배치했다. 게임에서는 GLB 하나(284,272바이트)를 읽어 선반과 다섯 묶음 종류를 총 여섯 번에 그린다. 상세 형상은 10m 안에서 보일 때 요청하고 13m 밖에서는 단순 형상으로 돌아간다.

760×480, 저사양 모드의 헤드리스 Chromium에서 기존 ‘꽃도매상가 입구’부터 진열면까지 실제로 약 50m 걸었다. 앞쪽 38.7m에서 파일 요청은 없었다. 이어지는 같은 11.4m 구간을 처음 걸을 때 프레임 시간 p95/최장은 기존 18.4/20.7ms, 변경 후 두 측정에서 18.5~18.6/26.8~27.6ms였다. 재방문 시 기존은 18.2/18.8ms, 변경 후는 18.4/19.0~19.2ms였다. 근처 세 시점에서는 상세 파일을 한 번씩 받았고, 등을 돌린 같은 위치와 먼 입구에서 시작하면 받지 않았다. 로컬 서버 측정값으로, 인터넷 다운로드 시간은 포함하지 않는다.
