# 경부선 1층 매표소 앞 대합실

짐캐리에서 무인발권기와 통합매표소로 이어지는 공개 대합실이다. 입구의 낮은 천장에서 꺾여 들어가는 흰 확산판, 그 뒤의 높은 곡면 간접등, 원형 급기구, 무인발권기 위 벽을 비추는 매입등을 블렌더에서 만들었다. 회베이지색 석재 사이로 짙은 띠가 지나가고, 점자블록은 기존 안내 데스크 앞에서 꺾인다. 타원형 안내 데스크와 기존 기둥의 자리는 유지하고 모서리, 상판 접합부, 금속 걸레받이를 입혔다.

## 사진과 배치

2023년 5월 현장 사진에는 안내 창구 옆 회색 바닥 띠, 무인발권기 뒤쪽의 둥근 벽, 벽을 따라 겹치는 밝은 원뿔, 천장의 흰 띠와 원형 급기구가 함께 보인다. 짐캐리 운영사 사진과 2025년 방문 기록으로 인접 창구를 대조했다. 촬영 시점별로 달라질 수 있는 자재 색과 표면의 결은 사진을 보고 새로 그렸다. 원본 사진의 픽셀은 제품에 들어 있지 않다. [2023년 5월 대합실 원경](https://naeuri-infor23.tistory.com/322) · [짐캐리 운영사의 서울고속버스터미널 지점](https://zimcarry.net/reserve/item.php?it_id=1606884478) · [2025년 방문 기록](https://dawn-sunup.tistory.com/718) · [네이버 지도 지점](https://map.naver.com/p/entry/place/1518242796)

기존 보행 조사 GB1F-32에서 특정한 높은 간접등 위치는 현지 모델 좌표 u54–62, v27–33에 남겼다. 다음 구간 v33–48의 높은 천장, 통합매표소와 짐캐리 사이 통로도 유지했다. 낮은 천장 3.3m와 높은 간접등 4.6m는 기존 모델 기준이다. 60cm 바닥 모듈, 석재 띠의 길이, 급기구·조명의 간격, 곡면 반지름과 광량은 사진에 맞춰 잡은 값이다. 유니클로 유리 벽의 문과 충돌 범위는 그대로 두고, 접근 시 두 겹 누적되던 반투명 처리를 고쳤다. ## 파일과 재현

`concourse-finish.blend`의 `Editable public concourse finishes` 컬렉션에서 10개 마감 부위를 개별 편집할 수 있다. `Distant · texture-free silhouette`에는 먼 거리 형상이 있다. 모델 원점은 u57, v29다. 실제 게임 보행 좌표는 `#/gyeongbu/1F?p=67.739,0,-56.505,173.464`다.

블렌더가 석재·회벽·금속·확산판을 위한 1024×512 공용 아틀라스를 생성해 원본에 내장한다. 조명과 바닥의 접촉 그림자는 정점 색에 저장한다. 런타임은 텍스처가 필요 없는 190개 삼각형 형상을 먼저 표시한다. 같은 층에서 이 구간을 보는 카메라가 22m 안에 오면 WebP가 내장된 155,564바이트 GLB를 한 번 읽는다. 30m 바깥에서는 다시 먼 형상으로 바뀐다. 두 형상 모두 한 번에 그려진다.

저장소 루트에서 다음 명령으로 재생성하고 보행을 검증한다. Blender 4.5.11 LTS를 사용했다.

```sh
blender -b --threads 2 --python-exit-code 1 -P assets/models/gyeongbu-concourse-finish/build.py
node assets/models/gyeongbu-concourse-finish/pack.mjs
node assets/models/gyeongbu-concourse-finish/check.mjs /tmp/gyeongbu-concourse-walk
```

정상 플레이에서 출입구를 3.30m 걸어 통과했고, 25.6–33.0m 구간의 두 보행선을 20cm 간격으로 검사했다. 위층·등진 시야·원거리에서 고해상도 요청은 없었고, 재진입 시 캐시를 재사용했다. 일출·낮·노을·밤·서울 실시간 모드도 확인했다. Metal Chromium, 1050×700에서 동일한 6.23m 보행을 전후 각 두 번 측정했다. 이전과 이후 모두 프레임 간격 95백분위는 16.7–16.8ms였고, 최대값은 각각 16.8ms와 33.3ms였다.
