# 하츠베이커리 · 스위트 파크

2026년 11월 26일 개점한 하츠베이커리 팝업을 센트럴시티 B1 스위트 파크 서측 매장에 배치했다. 11월 25일자 운영사 평면도에서 쓰던 셀 [1032, 540, 1079, 595]을 유지했다. 영업 기간은 보도자료에 ‘26일부터 3개월간’으로 기재돼 있다. [신세계 강남점 층별 안내](https://www.shinsegae.com/store/floor.do?storeCd=SC00002) · [파이낸셜포스트가 게재한 신세계백화점 제공 현장 사진 두 장](https://www.financialpost.co.kr/news/articleView.html?idxno=303445)

사진의 두 크림색 테이블과 황동색 모서리, 굽 달린 접시, 파란 종이 포장, 손잡이가 달린 꽃무늬 쇼핑백과 흰색 HAZ BAKERY 백을 모델링했다. 딸기 샌드베이글과 강남점 한정 타로두바이 샌드베이글은 절단면이 손님을 향한다. 가운데 접시에는 저당 팥빵이 놓인다. 진열대 폭 2.55m와 개별 집기 치수는 사진 속 비례를 따른 근사치다. 정면은 평면도 동쪽 통로를 향한다. [낮·밤 일반 게임 화면 비교](comparison.jpg)

Blender에서 `display.blend`의 `HazBakeryCounter` 컬렉션을 편집한다. 컬렉션 원점은 두 테이블 사이 상판 높이에 있다. 라이브러리와 실내 배치 목록에 같은 이름을 등록했다. 아래 명령은 편집본에서 런타임용 메시를 내보낸다.

```sh
cd assets/models/haz-bakery
blender -b display.blend -P export.py
```

초기 모델을 다시 만들 때만 `blender -b -P build.py`를 사용한다. 내보낸 GLB는 67,332바이트, 10,516삼각형, 단일 드로다. 9m 이내에서 진열대가 보일 때 요청하고 12m를 벗어나면 간략한 상판으로 돌아간다. 정면 일반 게임 주소는 `#/centralcity/B1?p=-47.140,-6.000,63.038,21.339,-4.000`이다.
