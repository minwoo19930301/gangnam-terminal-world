# 메가박스 앞 원형 광장과 카멜커피

백화점 강남점의 2026년 11월 25일 B1 고객용 층도에는 영화관, 카멜커피, 영풍문고 앞에 흰 원형 광장이 있고 식품관 사선 통로와 행사장 옆 통로가 이곳에 닿는다. 게임의 기존 평면에서는 지상 외벽선 아래가 잘려, 광장 한가운데에 서면 두 실내 페이지 모두에서 지하 1층 바닥을 뚫고 떨어졌다. 광장과 서측 공용 바닥을 같은 층도 축척으로 복원하고 기존 사선 통로의 끝 모서리에 맞췄다. 광장 안을 지나던 센트럴시티 옛 외벽도 층도에서 공용 바닥과 겹치는 범위만 천장 높이까지 열었다. [신세계백화점 강남점 층별 안내](https://www.shinsegae.com/store/floor.do?storeCd=SC00002)

카멜커피 운영사의 10호점 사진에서 검은 갓이 포개진 펜던트, 합판 뒤판, 붙박이 테이블을 확인했다. 2025년 8월 매장 정면을 찍은 방문 사진에는 같은 펜던트와 주문대, 회색 벽돌, 흰 상호가 한 화면에 보인다. 광장 석재 바닥의 테두리와 곡선 천장에 들어간 두 줄 조명은 이 사진을, 서점 쪽 열린 문턱과 간판은 같은 방문자의 서점 사진을 참고했다. 매장 폭과 천장 높이는 게임 축척에 맞춘 근사치이며 책 표지와 진열품은 예시다. 오래된 시설 자료의 분수는 현재 층도와 이 사진에서 확인되지 않아 재현 근거로 사용하지 않았다. [카멜커피 지점 안내](https://cmlandco.kr/Location) · [운영사 지점 사진](https://cmlandco.kr/web/_camel/store10.png) · [카페 정면 사진](https://neonmadbird.com/wp-content/uploads/2025/08/%EC%B9%B4%EB%A9%9C-1.jpg) · [서점 입구 사진](https://neonmadbird.com/wp-content/uploads/2025/08/%EC%98%81%ED%92%8D-1.jpg) · [과거 센트럴시티 시설 자료](https://www.codil.or.kr/filebank/original/MA/OTKCMA130074/OTKCMA130074.pdf)

편집 원본은 [front.blend](front.blend)의 CamelCoffeeRotaryFront 컬렉션이다. build.py로 원본을 생성하거나, 편집한 파일을 연 상태에서 export.py를 실행해 한 메시로 내보낼 수 있다. 글꼴 윤곽은 원본에 메시로 저장돼 있다. 게임은 광장에서 카페를 바라볼 때 상세 모델을 한 번 내려받는다. 같은 광장에서 사선 통로로 돌아서거나 먼 식품관을 열었을 때의 신규 요청은 0회였다. [일반 게임에서 광장 보기](https://minwoo19930301.github.io/gangnam-terminal-world/#/shinsegae/B1?p=-131.3662,-6,26.9379,164.4499) · [보행 시점 비교](comparison.jpg)

두 실내 주소에서 일반 보행 키로 원형 광장과 매표 로비 앞 사이를 왕복했다. 백화점 주소와 센트럴시티 주소 모두 보행 중 바닥 높이 −6m와 천장이 유지됐다. 중심부와 기존 사선 통로의 새 마감 면적이 겹치는 부분은 삼각형 교차 검사에서 0㎡였다. 서쪽 연결부는 층도 범위까지만 표현했다. [게임 보행 회귀 테스트](../../../tests/cinema-rotary.mjs)

행사장 옆 직선 벽이 스포츠 슈 전문관 쪽으로 꺾이는 지점에서 바닥과 천장을 같은 꼭짓점에 맞췄다. 지도에서 ‘원형 광장 옆 통로’를 골라 벽을 바라보면 보이던 실외 배경 틈이 닫힌다. 서쪽은 운영사 층도에 지하철 방향으로 열려 있다. 게임에서 이 개구부 너머는 대응하는 보행 바닥이나 전환문이 확인되지 않아, 그쪽을 보는 시점에는 실외 배경이 조금 남는다. [신세계 강남점 B1 고객 층도](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png)
