# 강남고속버스터미널점 홈웨어 매대

신반포로 194 터미널 지하 1층 44호의 다이소 본매장을 모델링했다. 2026년 4월 6일 방문 사진에서 기울어진 판에 걸친 연하늘색 곰무늬 잠옷, 목제 집게 옷걸이, 검은 후크에 걸린 파랑·베이지·짙은색 옷, 청록색 홈웨어 표찰을 확인했다. 매대 폭과 높이, 옷 수량, 통로 안의 정확한 자리는 추정이다. 게임에서는 고투몰과 연결되는 경부선 B1의 긴 매장 통로에 있다. [아성다이소 매장검색](https://www.daiso.co.kr/cs/shop) · [터미널 층별안내](https://exterminal.co.kr/floor.asp) · [방문자의 홈웨어 진열 사진](https://noopy0402.tistory.com/464)

[Blender 원본](homewear.blend)에서 옷·옷걸이·잠옷·곰무늬·경사판을 개별 편집할 수 있다. Blender에서 build.py를 백그라운드로 실행하면 원본과 게임용 GLB를 다시 생성한다. 매장 전면 6.3m 안에서 화면에 들어오면 고해상도 메시를 한 번 받는다.

같은 통로를 플레이어로 걸어 바닥 높이 −4m와 지점 이름, 최초 진입 시 파일 요청 0건, 매대 접근 후 요청 1건을 확인했다. 검증 명령은 저장소 루트에서 `node assets/models/daiso-homewear/check.mjs`이다.
