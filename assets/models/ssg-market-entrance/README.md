# 신세계 강남점 B1 마켓 동측 입구

2025년 2월 27일 비즈워치 기사에 실린 신세계 제공 사진에서 양쪽의 검은 대리석 원주 두 개씩, 흰 기단과 황동 돌림띠, 잎무늬 주두, 중앙 한자와 오른쪽 영문 명칭, 광택이 있는 인방 아랫면을 확인했다. 게임에서는 기존 출입구의 폭과 높이에 맞춰 모델링했다. 별도 시즌 사진에 기록된 녹색 장식은 인방 양 끝에 작게 남겼다. [기사와 사진 설명](https://news.bizwatch.co.kr/article/consumer/2025/02/27/0034) · [입구 사진](https://cdn.bizwatch.co.kr/news/photo/2025/02/27/80471a6781bc74f5e9c4cb362edd51d3.jpg)

[주간 로비와 야간 문턱에서 본 변경 전후](comparison.jpg) · [게임 카메라](camera.json)

Blender 원본은 `entrance.blend`의 `MarketEastPortal` 컬렉션이다. 원주와 기단, 주두, 문자 윤곽, 소핏과 시즌 장식을 각각 편집할 수 있다. 수정 후 이 폴더에서 `blender -b entrance.blend -P export.py`로 게임용 메시를 내보낸다. 원본 재생성 스크립트 `build.py`는 macOS의 Songti와 Georgia로 글자 윤곽을 만든다.

게임에서는 로비에서 출입구가 보이고 23m 이내에 들어오면 상세 메시를 한 번 불러온다. 상세형은 삼각형 10,401개, 원거리형은 292개이며 각각 한 번에 그린다. 기존 위치에서 앞뒤로 약 10.6m 걸어 동측 로비와 마켓 사이를 왕복했고, 뒤돌아선 로비 시점과 28m 밖에서는 원거리형만 사용했다.
