# 경부선 5~10번 승차홈 출발안내 전광판

2024년 광고 운영사 자료 88~90쪽의 경부선 승차게이트 사진에는 중앙의 검은 세로형 전광판, 좌우 유리 출입문과 독립 광고 패널, 기둥 하단 매입부가 보인다. 중앙 화면에는 승차홈 5~10, 당시 시계 14:08, 8행의 출발 시각·도착지·승차홈이 표시된다. 89쪽은 양옆 패널 규격을 약 1 × 2m로, 90쪽은 1.08 × 2.17m와 1.17 × 2.17m로 표기한다. 다른 부재 치수, 7번 앞 기존 모델과 사진의 대응, 모서리와 패널 이음새는 사진 비례로 재구성했다. 광고 그림은 사진의 색과 배치에 맞춰 Blender에서 면으로 제작했다. [광고 운영사의 현장 사진과 규격, 90쪽](https://ad-gangnam.com/wp-content/uploads/2024/03/2024_AD-GANGNAM_%EC%84%9C%EC%9A%B8%EB%B2%84%EC%8A%A4%EB%A7%A4%EC%B2%B4-%EC%A0%9C%EC%95%88%EC%84%9C.pdf#page=90)

상단 시계는 게임의 시간과 같다. 실시간 모드는 서울의 현재 시각을, 일출·낮·노을·밤은 선택한 미리보기 시각을 표시한다. 분이 바뀔 때 화면이 보이면 텍스처를 갱신한다. 목록은 현장 사진에 보이는 시간·승차홈과 터미널의 대표 도착지를 조합한 예시이며, 표 위에도 ‘출발 안내 · 예시’가 표시된다. [터미널 운영사 층별 안내](https://exterminal.co.kr/floor.asp)

[Blender 원본](./gates-5-to-10.blend)에서 세 외함, 보호유리 테두리, 개스킷, 모서리, 플린스와 좌우 라이트박스를 편집할 수 있다. 풀 모델은 전광판이 같은 층의 시야에 들어온 뒤 15m 이내에서만 요청된다. 중앙 LCD는 자체 발광 재질을 쓴다.

| 화면 | 게임 주소 |
| --- | --- |
| 출입문과 측면 패널 | `#/gyeongbu/1F?p=103.805,0,6.739,-69.19` |
| 중앙 화면 앞 | `#/gyeongbu/1F?p=105.768,0,5.993,-69.19` |

```sh
blender -b --threads 2 -P assets/models/gyeongbu-boards/build.py
blender -b assets/models/gyeongbu-boards/gates-5-to-10.blend --threads 2 -P assets/models/gyeongbu-boards/export.py
node assets/models/gyeongbu-boards/check.mjs
```

검사는 일반 게임에서 시계 다섯 모드와 분 변경을 확인한 뒤, 중앙 기둥 양쪽 문을 각각 걸어 통과한다. 마지막 인자로 이미지 저장 폴더를 지정하면 실시간·야간 화면도 캡처한다.
