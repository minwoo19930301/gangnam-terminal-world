# 인텔리젠시아 강남 커피바

신세계 강남점 B1 층도에서 보앤미와 와인하우스 맞은편, 소금집 옆에 있는 커피바를 표현했다. 빨간색 바와 흰 스툴, 청록색 드리퍼, 두 열 세 칸의 주황색 진열장, 둥근 벽 무늬와 격자 천장은 운영사가 공개한 강남점 사진 세 장을 기준으로 만들었다. 상품 종류와 간격은 예시이며 바의 길이와 깊이는 게임 속 점포 폭에 맞췄다. [강남점 사진과 안내](https://www.intelligentsia.com/pages/gangnam-coffeebar) · [백화점 층별 안내](https://www.shinsegae.com/store/floor.do?storCd=SC00002)

Blender 편집본 [coffeebar.blend](coffeebar.blend)의 `GangnamCoffeebar` 컬렉션을 수정한 뒤, 원본을 연 상태에서 `export.py`를 실행하면 게임용 모델을 다시 생성한다. 낮과 밤 모두 실내등 아래 진열된 제품이 보인다. 정면에서는 87,816바이트 GLB를 한 번 받았고, 같은 자리에서 반대 방향을 보거나 마켓 입구에 있을 때는 요청이 없었다.
