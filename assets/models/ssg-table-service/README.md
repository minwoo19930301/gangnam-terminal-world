# 신세계 강남점 평양면옥

11층 평양면옥 입구에서 왼쪽 첫 목제 식탁에 평양냉면 한 상을 차렸다. [일반 게임에서 보기](http://127.0.0.1:8765/?pos=-18.81965243440413,50.2,59.82356784260514&yaw=7.5&pitch=-48#/shinsegae/11F) · [게임 촬영본](game.jpg) · [냉면과 찬기 근접 화면](cold-noodles.jpg) · [시점 좌표](camera.json)

강남점 층별 안내에는 11층 식당가의 평양면옥이 냉면·불고기 매장으로 실려 있다. 신세계 매거진도 이 지점의 전통평양냉면을 소개한다. [신세계 강남점 층별 안내](https://www.shinsegae.com/store/floor.do?storeCd=SC00002) · [신세계 매거진 《냉면의 미각을 노래하다》](https://www.shinsegae.com/magazine/view.do?magSeq=904&pSeq=2078)

강남점 방문 사진에서 나무 식탁과 세로살 의자, 둥근 매립 덮개, 금속 냉면기와 면수 잔, 두 칸 찬기, 양념통, 종이 메뉴를 확인했다. 그릇에는 두 갈래로 접은 메밀 면발과 편육, 반으로 자른 달걀을 담았고 찬기에는 배추김치와 무김치를 나눠 놓았다. 치수와 좌석 위치는 추정했다. 메뉴는 촬영 당시의 책자 형태와 음식 이름을 바탕으로 다시 조판했고, 가격은 생략했다. [강남점 실내·상차림·메뉴 근접 사진](https://lifensook.tistory.com/154)

## Blender 원본과 게임 배치

편집 원본은 `table.blend`의 `SSG_11F_PyongyangMyeonok` 컬렉션이다. 미터 단위이고 원점은 식탁 중앙의 바닥이다. Blender +X는 두 의자를 잇는 방향, +Y는 냉면에서 메뉴 쪽, +Z는 위다. glTF Y-up 변환 후 게임 Y축으로 +20.780533° 회전해 월드 (−18.963960, 50.2, 58.880590)에 둔다. 전체 월드 지형 보정은 높이 −0.908m다.

면발은 원본 안의 숨겨진 하위 컬렉션 `평양면옥 · 메밀 면발 원형`에 있다. 두 묶음은 각각 폴리 스플라인 84가닥, 육수에 잠긴 끝은 24가닥이다. 국물 밖의 높이와 겹친 면의 그림자, 물에 잠긴 깊이에 따른 색 변화, 광택을 이 곡선에서 UV 색과 노멀 맵으로 구웠다. 게임에서는 구운 표면과 실제로 튀어나온 일부 면발을 함께 쓴다. 기울어진 삶은 달걀의 흰자와 노른자, 단면의 결이 다른 두 장의 편육, 절인 배추의 잎맥과 접힌 가장자리, 얇게 포갠 무김치를 각각 편집할 수 있다. 음식과 참나무의 이미지는 직접 생성해 원본에 내장했다.

Blender 3.6.23에서 원본을 다시 열어 식탁의 메시 143개와 면발 192가닥, 내장 이미지 2개를 확인했다. 메뉴 글자는 AppleMyungjo를 메시로 변환했다. 재생성할 때 한글 글꼴 경로는 `GTW_KOREAN_FONT`로 지정한다. 저장소 루트에서 실행한다.

```sh
D=assets/models/ssg-table-service
"${GTW_BLENDER_BIN:-blender}" -b --factory-startup --gpu-backend opengl --python-exit-code 1 -P "$D/build.py"
node "$D/pack.mjs"
```

편집한 `table.blend`를 게임용으로 다시 내보내려면 아래 명령을 사용한다. 면발 곡선을 수정했다면 `-- --rebake-noodles`를 붙인다. 내보낸 뒤에도 원본은 그대로 편집할 수 있다.

```sh
"${GTW_BLENDER_BIN:-blender}" -b --gpu-backend opengl "$D/table.blend" --python-exit-code 1 -P "$D/export.py" -- --rebake-noodles
node "$D/pack.mjs"
node tests/smoke.mjs shinsegae gotomall --quiet
```

배포 GLB는 577,220바이트와 삼각형 30,549개다. 식탁과 새틴 스테인리스를 각각 한 번씩 그린다. 일반 게임에서 다른 층, 같은 층의 먼 장소, 식탁 앞에서 천장을 향한 시점은 파일 요청이 모두 0건이었다. 바닥 쪽으로 고개를 내려 한 번 요청했고, 보행한 뒤 물러나 다시 보았을 때도 누적 1건이었다. 수정하지 않은 원본에서 면발을 다시 굽고 압축하면 같은 GLB가 나온다.
