# 오픈 스테이지의 흰 소파

센트럴시티 광장 보행 영상의 CC-D2 프레임 기록에는 LED 기둥 사이에 흰 소파와 테이블이 보인다. 게임의 소파 두 개와 테이블 두 개가 놓인 자리에 맞춰 쿠션과 파이핑, 낮은 금속 다리, 석재 상판과 도자기 커피잔을 만들었다. 가구 치수와 세부 마감, 잔의 모양은 게임용 추정이다. [광장 보행 영상](https://www.youtube.com/watch?v=FeFx7kfWgdo&t=233s) · [현장 프레임 검토 기록](../../../data/research/centralcity.json)

가구 네 점과 찻잔 두 벌을 원본에서는 따로 편집할 수 있다. 게임에서는 광장을 가까이서 볼 때 31,368바이트 GLB를 한 번 받아 5,800개 삼각형을 한 번에 그린다. [블렌더 원본](lounge.blend) · [일반 게임](https://minwoo19930301.github.io/gangnam-terminal-world/#/centralcity/1F?p=-51.211,0.000,78.457,29.962) · [낮 플레이 화면](lounge.jpg)
