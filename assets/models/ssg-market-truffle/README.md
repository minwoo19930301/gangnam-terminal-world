# 타르투플랑게 · 신세계 마켓

2025년 2월 현장 취재에서 생트러플이 프루니에 캐비아 옆에 있었다고 기록했다. 두 현장 사진에는 붉은 대리석 상판, 파란 냉장등, 아래쪽 나무 트레이 두 개에 놓인 검은 생트러플과 위쪽의 개별 포장, 옆 매대의 오일병과 포장 식품이 보인다. 기존 시장 안 프루니에 옆 목공 한 칸에 같은 구성을 넣었다. 정확한 칸·너비와 어느 쪽에 있었는지는 공개 도면에 표시되지 않아 게임 내 위치는 추정했다.

기존 자동 배치의 병 진열대가 냉장장 앞에 약 24cm만 남겨 보행자가 들어갈 수 없었다. 해당 진열대 하나를 1.05m 안쪽으로 옮겨 양쪽 통로를 열었다. 병·단 수·매대 폭은 보존했다. 정상 W 왕복으로 냉장고 앞 12.94m와 옮긴 진열대의 반대쪽도 확인했다.

Blender 원본 `counter.blend`의 `TruffleMarketCase` 컬렉션에서 냉장고, 트레이 두 개, 개별 생트러플·포장, 오일과 대리석을 편집한다. 이 폴더에서 원본 빌드는 `blender -b -t 4 -P build.py`, 원본 편집 후 게임 내보내기는 `blender -b -t 4 counter.blend -P export.py`로 실행한다. 근접 시 파일 123,032바이트와 삼각형 5,990개를 1드로로 그린다. [낮·밤과 상품 시점](comparison.jpg)
