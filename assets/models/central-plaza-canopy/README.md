# 센트럴시티 조각광장의 캐노피

서울연구원이 2020년 6월 신반포로에서 찍은 사진에는 세 구체와 동쪽 화단 사이로 네 모서리의 목재색 기둥, 칸이 나뉜 밝은 처마, 적갈색 지붕 루버가 보인다. 지붕 아래에는 회색 세로판과 얇은 선반, 밝은 좌판이 있다. 같은 시설을 2022년과 2026년 거리뷰에서도 확인했다. 기둥 간격과 화단으로부터의 이격은 사진 비례로 잡았다. [서울연구원 원사진](https://data.si.re.kr/photo/06o03212db30000) · [2022년 7월 거리뷰](https://map.naver.com/p?c=18.00,0,0,0,adh&p=nuDLz2BbheMIjZ_ZXc2BRg,160,-8,80,Float) · [2026년 1월 거리뷰](https://map.naver.com/p?c=18.00,0,0,0,adh&p=FmNf2XmJtk1RjDP3k0TI7A,163,0,80,Float)

`canopy.blend`의 `CentralCityCourtCanopy` 컬렉션에서 67개 부재를 개별 편집할 수 있다. 지붕은 수평이고, 기둥 밑면과 벤치 받침은 각 지점의 게임 지형 높이에 맞췄다. 기둥·좌판·상판·처마의 단순 형상은 원본에서 추출해 먼 거리의 모델과 충돌 영역에 쓴다. 근거리 GLB는 한 번에 그린다. 원본에서 다시 내보내려면 이 디렉터리에서 아래 명령을 실행한다.

```sh
blender -b -t 4 canopy.blend -P build.py -- --export-current
```

12시 30분과 22시의 같은 거리 시점에서 비교했다. 의자와 기둥 사이로 통과하는 시점도 함께 기록했다. [게임 전후](comparison.jpg) · [시점](camera.json)
