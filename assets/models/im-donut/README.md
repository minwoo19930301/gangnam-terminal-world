# 아임도넛 · 신세계 강남점

2026년 11월 25일자 스위트 파크 안내도 북측 매장을 사용했다. 7월 백화점 현장 사진에서 네모난 분홍 도넛, 녹색 꽃잎 모양 도넛, 갈색 글레이즈 링, 크림색 접시, 영문 상호를 찍은 흰 포장 상자가 보인다. 7월 25일 기자의 현장 사진에서 통로 쪽 검은 간판과 목재 틀, 실제 공개 조리창에 보이는 스테인리스 후드·믹싱볼·물음표 트레이를 확인했다. 판매 면과 조리창의 크기 및 한 접시에 담은 수량은 사진을 참고한 게임용 근사치다.

- [신세계 제공 지점 사진과 한정 상품](https://www.shinsegaegroupnewsroom.com/shinsegae-department-store-gangnam-imdoughnut-first-retail/)
- [동아일보 현장 사진, 매장 앞과 조리창](https://v.daum.net/v/20260725100217428)

편집 원본은 `display.blend` 안의 `ImDonutGangnam` 컬렉션이다. 입면, 포장, 도넛 반죽, 상품별 글레이즈와 각 조리 집기를 개별 편집할 수 있다. 이 디렉터리에서 원본 재생성은 `blender -b -t 4 -P build.py`, 편집한 원본의 게임 내보내기는 `blender -b -t 4 display.blend -P export.py`로 실행한다. 202,076바이트, 17,696삼각형, 한 드로로 내보낸다. 전방 12m 안에서는 상품이 있는 원본을, 멀리서는 요청 없이 목재 입면과 조리창·포장 윤곽을 표시한다.

기존 검색 결과와 도착점은 그대로 쓰며 `camera.json`에 정상 주소를 기록했다. [게임 도착 시점 및 상품 비교](comparison.jpg)
