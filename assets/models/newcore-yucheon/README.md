# 뉴코아아울렛 강남점 1관 5층 유천냉면

이랜드리테일의 강남점 층 안내에서 1관은 5층 전문식당가·문화센터·VIP라운지, 2관은 5층 남성·골프가 최상위 영업층이다. 3관은 1층 식당가만 안내한다. 1관 5층 식당 목록에 유천냉면이 있다. [1관 5층 식당 목록](https://www.elandretail.com/m/store/store_04.do?bdID=0003001B&branchID=00110001&displaySeq=5&floorID=0002005F&lang=000600KO) · [2관 층별 안내](https://www.elandretail.com/store02.do?BDID=0003002B&branchID=00110001&lang=000600KO) · [3관 층별 안내](https://www.elandretail.com/store02.do?BDID=0003003B&branchID=00110001&lang=000600KO)

2022년 7월 방문자가 직접 촬영한 입구와 홀 사진을 바탕으로 유천냉면의 열린 입구에 흰색 상호, 짧은 반원 기와 처마와 메뉴 입간판을 설치했다. 복도에서 보이는 식당 안쪽에는 검은 의자, 사각 종이등, 액자가 걸린 목재 패널과 청록색 벽을 배치했다. 사진은 당시 모습을 기록한다. 현재의 개별 좌석 배치와 실제 매장 실측 치수는 확인되지 않았으며 게임의 기존 문턱과 폭에 맞췄다. 메뉴판의 그릇 그림은 직접 만든 예시다. [강남점 방문 사진](https://96930021.tistory.com/entry/뉴코아강남-유천냉면)
