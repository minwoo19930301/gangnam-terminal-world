# 서울고속버스터미널 일대 가로수와 가로등

편집 원본에는 느티나무·은행나무·소나무·벚나무·단풍나무의 가까운 수형과 먼 수형, 9m급 곡선 가로등이 들어 있다. 나무는 줄기에서 가지가 갈라지는 높이, 위로 좁아지는 은행잎 수관, 소나무의 층진 가지, 넓은 느티나무 그늘을 구분했다. 잎 무늬를 원본에 포함했고, 가로등은 기둥과 렌즈를 나눠 낮과 밤의 발광을 따로 제어한다. 가지의 모양과 등기구는 게임에 맞춰 설계했다. 개별 수목의 수종이나 실제 지주의 규격은 현장에서 조사하지 않았다. [거리뷰](https://map.naver.com/p?c=18.00,0,0,0,adh&p=mU8aHacBJYgq0X7dtSPrtw,-88,10,80,Float) · [게임 화면](preview.jpg)

`streetscape.blend`에서 수형, 재료색, UV, 잎 무늬와 등기구를 편집할 수 있다. 웹에서 읽는 형상은 다음 명령으로 내보낸다.

```sh
blender -b assets/models/streetscape/streetscape.blend --python assets/models/streetscape/build.py -- --export-current
```

현재 OSM에 상세 장소의 점유 범위를 적용한 공통 시가지에서 나무 9,361그루와 가로등 913개를 셌다. 상세 장소가 직접 심은 나무에도 같은 `K.tree` 렌더러가 적용된다. 공통 시가지의 나무 좌표·높이·수종, 충돌벽 15,755개와 바닥·경사 1,588개의 인자열은 교체 전후 해시가 일치했다. 낮과 밤 도로 화면, 발광 전환, 수변과 거리 모듈의 보행 검사를 함께 확인했다.

| 공통 시가지 수목 9,361그루 전체 | 이전 | Blender 원본 반영 후 |
|---|---:|---:|
| 전부 근거리일 때의 삼각형 | 973,544 | 1,797,312 |
| 전부 원거리일 때의 삼각형 | 299,552 | 299,552 |
| 공간 타일 단위 인스턴스 묶음 | 164 | 228 |

이 값은 모든 나무를 한 수준으로 합산한 상한 비교다. 실제 화면은 공간 타일에서 150m 떨어지면 먼 수형을 고르고, 카메라 밖 타일을 제외한다. 한 나무의 줄기와 잎은 같은 메시와 재질을 사용한다.
