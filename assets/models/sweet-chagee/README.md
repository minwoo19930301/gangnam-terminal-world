# 스위트 파크 B1 · 차지 티 바

[게임의 매장 입구](https://minwoo19930301.github.io/gangnam-terminal-world/#/centralcity/B1?p=-56.537,-6,93.646,154.941,5) · [같은 통로에서 본 낮과 밤 전후 비교](comparison.jpg)

기존 게임에서는 ‘차지’ 아래 유리장에 페이스트리가 놓여 있었다. 2026년 11월 25일자 운영사 층별도에서 차지는 부창제과 옆, 치폴레 건너편이다. 브랜드 매장 안내에도 강남점 B1 스위트파크가 나온다. [신세계 강남점 고객 층별도](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png) · [차지 코리아 매장 안내](https://chagee.co.kr/kr/ko/stores)

7월 강남점 개점 이미지에서 인방 가운데가 통로 쪽으로 둥글게 나오고, 원형의 붉은 상표 아래 흰 타일 기둥이 두 갈래로 뻗는 모습을 확인했다. 개점 후 방문 사진을 대조해 빛이 비치는 목재 격자, 석재 티 바, 점등된 선반의 남색 차 포장, 픽업 번호와 TEA BAR 글자를 만들었다. 상표 윤곽은 브랜드 공식 페이지의 벡터를 사용했다. 집기 치수, 광량, 진열 수량은 게임 축척에 맞춘 근사값이다. 7월 이미지에 보이는 계단과 난간의 정확한 단차·위치를 확인할 수 없어 이번 점포 모델에는 포함하지 않았다. [개점 당시 강남점 전경](https://zdnet.co.kr/view/?no=20260716145243) · [강남점 방문 사진](https://witholddog.tistory.com/402)

지도에서 **차지** 또는 **CHAGEE**를 검색하면 고객 통로에서 상표와 픽업대를 함께 본다. 공식 층별도의 지하철 방향 입구에서 매대 사이를 지나 게임 거리 약 79m를 걸어 도착했다. 지하철 개찰구부터의 거리는 재지 않았다. 기존 매대의 평면 충돌 경계는 유지하고 높이를 새 상판과 맞췄다.

`counter.blend` 안의 `ChageeGangnamShop`에는 석재, 차 선반, 타일 기둥과 격자, 픽업대, 브랜드 표식을 따로 편집하도록 나눴다. 통합 도시의 실내 배치는 게임의 매장 변환 행렬에서 추출한다. 게임 상세는 126,612바이트, 12,765개 삼각형, 메시 한 개다. 근접 시점 두 곳에서 각 1회 요청했고 뒤돌아본 시점과 먼 통로에서는 요청이 없었다.

이 디렉터리에서 편집본을 다시 내보낼 수 있다.

```sh
blender -b --factory-startup -t 4 counter.blend --python-exit-code 1 -P export.py
```
