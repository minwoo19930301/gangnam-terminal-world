# 파미에스테이션 1층 식당가

신세계센트럴의 파미에스테이션 사진에서 천창을 사이에 두고 한쪽에는 벽돌과 반원창이, 맞은편에는 짙은 사각 격자창과 밝은 석재 기둥이 이어진다. IDBR의 프로젝트 사진에는 반원창 아래 Wafille 간판이 보인다. 게임에서 이 간판을 기준으로 맞은편의 기존 식당 네 칸과 기둥 다섯 개에만 마감을 적용했다. 사진에서 읽을 수 없는 경간 치수와 창짝의 접힌 각도는 기존 게임 벽체에 맞췄다. [운영사 소개](https://www.shinsegaecentral.com/famille) · [운영사 실내 사진](https://www.shinsegaecentral.com/public/img/famille_block_1_img.png) · [IDBR 사진](https://cdn.imweb.me/thumbnail/20240802/fd93989660b8b.png)

Blender 파일의 두 컬렉션에서 접힌 창짝, 철제 격자와 경첩, 반사되는 상점 띠, 석재 줄눈과 기단을 편집할 수 있다. 유리와 석재의 표면 무늬는 직접 제작했다. 게임에서는 두 인스턴스 묶음으로 그린다. 통로 쪽에서 화면에 들어온 경간이 19m 이내면 상세 모델을 요청하고 23m를 벗어나면 단순 형상으로 돌아간다.

[세 시점의 변경 전후](comparison.jpg) · [카메라 위치](camera.json)

헤드리스 Chromium 저사양 모드(640×400)에서 120프레임 동안 약 8.5m 걸었다. 두 번씩 측정한 프레임 시간 p95는 기존 20.7~20.9ms, 변경 후 20.5~21.0ms였다. 드로 호출은 321~340회에서 323~342회로 늘었다. 낮과 밤 모두 일반 입장으로 같은 세 시점을 확인했다. 원거리 시작점에서 상세 모델과 마감 이미지 요청은 각각 0회였다.
