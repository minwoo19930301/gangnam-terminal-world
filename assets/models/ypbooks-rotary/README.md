# 영풍문고 강남신세계점

신세계백화점 B1 고객 층도에 표시된 서점 셀과 기존 원형 광장의 5m 입구에 맞춘 매장 전면이다. 영풍문고 공식 매장 안내에서 지점명과 층을 확인했다. 지점 운영사가 제공하는 이미지는 매장 안내도이다. 외관은 2025년 8월 방문자가 원형 광장에서 정면으로 촬영한 사진을 참고했다. [영풍문고 지점 안내](https://www.ypbooks.co.kr/shopInfo/select-info/6550) · [운영사 매장 안내도](https://www.ypbooks.co.kr/shopInfo/guide/6550) · [백화점 층도](https://www.shinsegae.com/store/floor.do?storeCd=SC00002) · [입구 사진](https://neonmadbird.com/wp-content/uploads/2025/08/%EC%98%81%ED%92%8D-1.jpg)

사진에서 보이는 회색 벽돌 간판대, 흰 한글과 붉은 심벌, 안쪽 작은 간판, 중앙의 층진 책 전시대, 왼쪽 신간 서가를 편집 가능한 부품으로 만들었다. 책 표지와 제목선은 예시다. 입구 폭과 깊이는 기존 게임의 원형 광장 문턱을 따라 축약했다. 근거리 모델은 정점 색을 쓰는 65,216바이트 GLB 한 개다. 원형 광장에서 서점을 등지거나 먼 식품관을 열면 다운로드하지 않는다.

## 입구 왼쪽 독서 공간

2025년 8월 2일 강남신세계점 방문자가 같은 방향에서 촬영한 입구와 실내를 대조했다. 사진에서 왼쪽의 낮은 이동식 진열대 뒤로 검은색 챌판과 나무 디딤판이 이어진다. 그 위에는 방석이 있는 독서 좌대, 밝은 목재 서가, 가지처럼 갈라지는 목재 기둥과 검은 스폿 레일이 보인다. 기존 모델의 입구 뒤 벽을 이 부분만 열고 고객용 공간을 폭 약 2.5m로 축약했다. 책 표지는 예시이며 실제 서가 치수와 판매 순위를 나타내지 않는다. [입구 사진](https://neonmadbird.com/wp-content/uploads/2025/08/영풍-1.jpg) · [독서 공간 사진](https://neonmadbird.com/wp-content/uploads/2025/08/영풍-2.jpg) · [운영사 지점 안내](https://www.ypbooks.co.kr/shopInfo/guide/6550) · [백화점 B1 도면](https://www.shinsegae.com/cms12/SC00002/guide/floor/__icsFiles/afieldfile/2026/11/25/GnV7UuBEdq7K.png)

광장에서 고객 보행으로 입구의 두 진열대 사이를 지나 세 단을 올랐다. 게임 바닥 높이는 -6m에서 -5.52m로 바뀌었고, 같은 길로 돌아와 광장에서 다시 -6m였다. 원형 광장에서 서점을 바라볼 때는 52,140바이트 입구 모델만 요청한다. 입구로 접근해 독서 공간이 보일 때 133,828바이트 GLB 한 개를 추가한다. 같은 위치에서 등지면 두 파일 모두 요청이 없었다. 독서 공간은 한 번에 그리며 삼각형 11,134개다. [낮과 밤의 동일 시점 비교 및 내부](reading-comparison.jpg)

편집용 원본은 reading.blend의 YPBooksReadingBay 컬렉션이다. 이 디렉터리에서 `blender -b reading.blend -P export-reading.py`를 실행하면 게임 GLB를 다시 만든다. 같은 원점의 front.blend에는 바깥 간판과 낮은 이동식 진열대가 있다.
