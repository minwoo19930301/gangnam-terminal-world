# 고투몰·한강 연결 보행통로의 피카소 벽화길

서초구가 2025년 12월 준공한 벽화길에는 레일 조명, 벤치와 LED가 있다. 2026년 1월 서울시 현장 사진에서 원형 기둥 사이의 낮은 좌석, 벽화를 비추는 작은 회전등, 반대 벽의 검은 영상 패널과 청록·보라·연황색 선형 조명을 확인했다. 화면 가운데에는 세로 홍보 영상이 나온다. 서초구가 10월 제공한 사진은 좌석 밑이 열려 있고 양끝을 바닥으로 접은 파란색과 흰색 벤치, 상판의 작은 표지를 보여준다. [서초구 준공 안내](https://www.seocho.go.kr/site/seocho/ex/bbs/View.do?bcIdx=406540&cbIdx=61) · [서울시 1월 현장 사진](https://mediahub.seoul.go.kr/archives/2016771) · [서초구 제공 10월 벤치 사진](https://cdnimage.dailian.co.kr/news/202610/news_1793174694495_1707525_m_2.png)

게임에서는 공공보행통로 B1 ‘피카소 벽화길’로 이동하면 볼 수 있다. 벤치 세 개를 기둥 사이에 배치하고 벽화 쪽에 조명 레일을 연결했다. 반대편 검은 벽의 화면은 블랙 바, 하단 덮개, 프레임과 표시 면으로 나뉜다. 서초구는 벽화 길이를 65m로 안내한다. 게임 내 벤치 길이 1.98m와 높이 0.466m, 등기구 내역·수량·위치, 화면 치수와 인쇄 장식은 사진 비례로 맞춘 값이다. 네이버 지도에서 확인한 관광안내센터는 같은 통로의 기준점이다. ## Blender와 공개 표시 화면

`gallery.blend`에는 일곱 종류의 집기·표시 면을 구성하는 메시 232개와 홍보 그림을 구성하는 메시 70개가 있다. 그림은 쇼핑, 반포의 저녁, 벽화길 좌석을 주제로 직접 제작했다. 원본의 두 번째 장면에서 수정해 내보내면 게임에서 세 장면이 6.5초 간격으로 바뀐다. 광원색 처리는 표시 면과 선형등에 적용했다. 검은 벽판, 하우징, 벤치는 게임의 실내 조명을 받는다.

```sh
blender -t 3 -b assets/models/sebit-gallery/gallery.blend --python-exit-code 1 -P assets/models/sebit-gallery/export.py
node assets/models/sebit-gallery/check.mjs
```

원본의 초기 형태를 재생성할 때는 다음 명령을 사용한다.

```sh
blender -t 3 -b --python-exit-code 1 -P assets/models/sebit-gallery/build.py
```

웹 모델 여섯 개는 합계 158,708바이트, 화면 전체 그림은 36,760바이트다. 서로 마주 보는 두 구역을 따로 읽고, 같은 LED 다섯 개는 받침과 확산판마다 한 번에 그린다. 양쪽 모두 보아도 각 파일은 한 번 읽는다. 벤치 옆을 걸었을 때 바닥 높이 −6m를 유지했고, 좌판을 밟은 위치는 −5.534m였다. 벽 뒤와 벽화를 바라보는 시점에서는 LED 벽 관련 파일 요청이 없었다. Blender의 통합 배치 33개와 게임 행렬의 최대 좌표 차이는 0.1365mm였다.

## 그리기 횟수

기존 원더스트리트의 색판 250개와 현수선 250개를 3.4m마다 묶었다. 건너편과 화면 가장자리를 포함한 네 시점에서 전시물만 같은 카메라와 빛으로 그려 원본과 대조했다. 각 1100 × 720 화면에서 바뀐 픽셀은 0~4개였고 색 채널 차이는 최대 1/255였다. 네 시점의 그리기 호출은 496→10, 260→9, 461→10, 96→4였다. 근처 전시 스위치를 껐다가 새 구간으로 걸어가도 공중 색판은 꺼진 상태를 유지했다.

같은 기기에서 전체 게임의 여덟 보행 시점을 전후 각각 72프레임 측정했다. 긴 회랑 시점의 전체 그리기 호출은 925→445, 반대쪽에서는 910→517이 됐다. 새 벤치와 조명 곡면 때문에 시점별로 삼각형이 늘었고, 두 긴 시점은 151,114→158,366, 227,571→239,054였다. 여덟 시점 전체의 프레임 간격 95백분위는 전후 16.7~16.8ms였다.
