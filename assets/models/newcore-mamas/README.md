# 뉴코아 강남점 3관 카페 마마스 외벽

잠원로 보도에서 카페 차양을 올려다보면 아치 안쪽의 숫자 3과 ‘뉴코아3관’ 금속 글자가 보인다. 방문자가 2025년 4월 10일 찍은 정면 사진에 이 표식과 검은 차양의 흰색 ‘café MAMAS’ 글자가 함께 나왔다. 밝은 금속 앞면과 짙은 측면, 위아래 가로 띠, 아치 안쪽 세 줄, 차양의 세로 이음선, 왼쪽 창 하단의 반투명 마감과 오른쪽 검은 판을 재현했다. 게임 내 치수와 차양 경사는 사진 비율에 맞춘 근사다. [방문자의 3관 입구 사진](https://skynarara.tistory.com/142)

이랜드리테일의 층별 안내는 3관을 1층 푸드로 표시한다. 게임에서 이 입구는 북쪽 킴스클럽 동에 있고, 잠원로4길 쪽 끝의 파란 P 및 킴스클럽 차양과 같은 가로 입면을 쓴다. 별도 주차 건물은 3관과 2관 사이에 있다. 주차타워 영상에 나온 층수는 외벽 제작에 사용하지 않았다. 편집용 컬렉션 이름은 `NC_MamasStreetFront`, 게임 오브젝트 이름은 `뉴코아 3관 · 카페 마마스 외관`이다. 컬렉션 원점은 기존 마마스 칸 중앙 외벽의 게임 바닥이다. 게임 배치는 `(189.18120, 0, -581.20215)`, Y축 회전은 `1.94233673`라디안이며, 도시와 결합할 때는 기존 지형 오프셋을 한 번 적용한다. Blender에서 형상을 고친 뒤 다음 명령으로 한 개의 웹 메시를 다시 내보낼 수 있다.

```sh
blender -b --factory-startup assets/models/newcore-mamas/front.blend -t 4 --python-exit-code 1 -P assets/models/newcore-mamas/export.py
```

저사양 일반 거리 화면에서 정면·비스듬한 접근·문 앞은 각각 60,520바이트의 메시를 한 번 요청했다. 새 탭에서 같은 보도의 반대 방향을 보거나 1관 5층에 도착하면 요청은 0건이었다. 정면 주간은 486→487회, 야간은 848→849회 그렸고, W로 같은 문턱을 지나 6.06m 걸은 종점이 전후 일치했다. 편집용 원본을 다시 열어 내보낸 GLB의 SHA-256도 최초 생성물과 같았다.
