# 키친205와 쇼토 · 강남점 스위트 파크 B1

북쪽 공용 통로에서 마주 보는 두 냉장 매대의 진열이다. 키친205는 원형 딸기밭 케이크 두 크기, 크림에 비치는 딸기 단면, 생딸기 테두리, 타원형 픽과 손잡이 달린 분홍 상자를 모델링했다. 쇼토는 흰 받침 위 사각 층케이크에 자른 딸기와 검푸른 베리를 올리고, 뒤편에 남색 리본을 단 흰 포장과 작은 검은 상호판을 두었다.

신세계 뉴스룸은 강남점 도입 당시 쇼토의 딸기 케이크와 브랜드 사진을 소개한다. 실제 진열·상품 형태·포장은 각 매장의 강남점 방문 사진으로 대조했다. 쇼토 초코딸기 제품은 해당 지점에서 구매한 방문 영상에도 나온다. 진열 수와 비율은 게임의 기존 매대 안에 맞춘 근사치다. [신세계그룹 뉴스룸](https://www.shinsegaegroupnewsroom.com/go-field-life-dessert-renewal/) · [키친205 강남점 실물 사진](https://go-dale.tistory.com/102) · [쇼토 강남점 매대·단면 사진](https://nomo.asia/513) · [쇼토 강남점 방문 영상](https://www.youtube.com/watch?v=9h42C_Bc0Ys)

`cakes.blend`에서 `SweetKitchen205`와 `SweetShoto`를 따로 편집한다. 두 컬렉션 모두 자체 로컬 원점을 쓰며 월드 배치는 각 매대의 기존 도면 셀을 따른다. 이 디렉터리에서 편집 결과를 각각 단일 표면 GLB로 내보낸다.

```sh
blender -b cakes.blend -P export.py
```

게임에서 각 매대는 쇼핑객 쪽을 보고 7m 안에서 프러스텀에 들어올 때 상세 파일 하나를 읽는다. 나란히 놓인 두 매대가 한 화면에 들어올 때는 양쪽 진열을 함께 볼 수 있다. 키친205는 116,452바이트·11,235삼각형, 쇼토는 78,876바이트·7,469삼각형이다. 지도에서 방문할 때 보이는 낮 풍경과 밤 근접 시점은 [게임 화면 비교](comparison.jpg)에 실었다.
