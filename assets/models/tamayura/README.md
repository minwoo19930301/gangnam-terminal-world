# JW 메리어트 서울 2층 타마유라

게임의 호텔 2층 로비에서 황동색 현관을 지나면 입구 티 바, 데판야키 바, 편백 스시 바를 볼 수 있다. 지도 검색에는 각 카운터의 관람 위치가 있다. [실제 게임 전후 화면](play.jpg) · [Blender 카운터와 상차림](studio.jpg)

호텔은 350년산 편백을 사용한 스시 카운터 8석, 데판야키 8석, 입구 티 바 6석을 안내한다. 호텔 사진에서 확인되는 흰 부조 벽, 검은 상판과 금속 후드, 매단 찻장, 서로 다른 두 종류의 의자를 제작했다. 지도에서 확인되는 주소는 서울 서초구 신반포로 176, JW 메리어트 호텔 서울 2층이다. 방 크기와 가구 사이의 간격은 기존 게임 건물에 맞춘 추정값이다. 금속 벽 무늬, 계절 장식과 음식 조합은 새로 만든 표현이다. [네이버 지도](https://map.naver.com/p/entry/place/1251661551) · [호텔 공식 사진](https://tamayura.jwmarriottseoul.com/ko/photos) · [공식 레스토랑 소개](https://www.marriott.com/ko/dining/restaurant-bar/seljw-jw-marriott-hotel-seoul/6409183-.mi) · [공식 메뉴](https://tamayura.jwmarriottseoul.com/ko/our-menus)

`tamayura.blend`의 공개 카운터 장면과 실제 게임은 같은 48개 배치를 사용한다. 별도 편집 장면에 12개 컬렉션, 995개 편집 메시가 있다. 의자와 개인 상차림은 원본을 고치면 연결된 모든 자리에 반영된다. 편백·직물·화강석 등은 절차적으로 그린 공통 재질을 사용한다. 여덟 면광원과 실제 가구가 만드는 빛과 그림자를 Cycles에서 두 번째 UV에 굽는다. 매장·시간대의 조명과 재질 반사는 플레이 중 계속 적용된다.

저장소 루트에서 다음 명령으로 원본, 표면, 조명 지도와 압축 메시를 재생성하고 일반 보행을 검사한다.

```sh
blender -b --factory-startup -t 4 --python-exit-code 1 -P assets/models/tamayura/build.py
node assets/models/tamayura/check.mjs
```

카운터별 의자와 냅킨은 같은 지오메트리를 인스턴싱한다. 총 19개 상세 파일은 해당 부분이 보이고 가까워졌을 때 사용한다. 14.14m 입장 보행, 네 가지 고정 시간 및 서울 실시간, 다른 층·후벽 너머·반대 시선에서의 신규 파일 요청 0회, 되돌아왔을 때 파일별 1회 다운로드를 검사한다. 플레이버즈·카페 원·파티세리 집기는 각 식당 단위로 처리한다. 1120×720 스시 바 관람 시점에서 같은 장면의 제출 삼각형은 732,410개에서 538,690개로 줄었다.
