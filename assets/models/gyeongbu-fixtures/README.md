# 경부선 도매상가와 지하 다이소 진열 로딩

게임은 같은 층에서 화면에 들어오는 매장을 확인한 후 해당 품목의 파일을 받는다. 원본은 [경부선 도매상가 Blender 파일](../gyeongbu/market.blend)과 [다이소 Blender 파일](../daiso/shop.blend)에 들어 있다. 도매상가 6종과 다이소 8종의 이름·정점·면·색·배치 행렬은 기존 GLB를 따른다.

## 거리별 표시

- 처음 한두 프레임이나 전송 중에는 진열장에 맞는 크기의 선반·벽체가 보인다.
- 같은 층의 시야에서 진열장 중심까지 54m 이내로 접근하면 간략화한 색상 메시를 받는다. 파일당 554~3,917바이트다.
- 19m 이내에서는 해당 품목의 원본 GLB를 받고 25m까지 유지한다. 별도로 제작한 상층 5곳의 대표 점포는 12m에서 상세 모델을 받고 16m까지 유지한다.
- 같은 장식이 반복돼도 한 종류당 한 번만 전송한다. 일시적인 전송 실패 시 앞서 받은 메시를 유지하며, 계속 바라보고 있으면 5초 뒤 재시도한다.

## 실제 게임에서 측정한 파일 용량

Chromium에서 네 가지 시작 위치를 각각 새 게임으로 열고 브라우저 응답 본문을 확인했다. 표의 합계는 위의 두 진열 라이브러리에 해당하는 GLB와 간략화 메시의 크기다.

| 시작 위치와 시야 | 변경 전 | 변경 후 | 받은 품목 |
|---|---:|---:|---|
| 경부선 앞 도로 | 1,060,460 B | 0 B | 없음 |
| 3층 생화시장 | 1,060,460 B | 0 B | 없음 |
| 8층 여성복 복도 | 1,060,460 B | 29,251 B | 여성복 26,552 B와 간략화 메시 2,699 B |
| B1 문구 진열대 정면 | 1,060,460 B | 121,352 B | 문구 118,068 B와 간략화 메시 3,284 B |

1층 승차권 발매기, B1 문구·식기·셀프계산대·간판, 상층 일반 의류점과 별도 신사복 점포의 7개 카메라에서 원본과 분할 모델을 비교했다. 메시별 정점·삼각형 수가 같았다. 각 장면에서 뽑은 47개 정점의 월드 좌표 성분 오차는 최대 0.000015m였고 색상 값은 모두 일치했다.

[B1 문구 진열대 게임 화면](paper.jpg) · [B1 식기 진열대 게임 화면](plates.jpg)

B1 문구 매대 앞에서 오른쪽으로 6.23m 걷는 입력을 기존·변경·변경·기존 순으로 실행했다. 1110×735, DPR 1, 고정 해상도, Chromium Metal에서 p95 프레임 간격은 각각 16.7, 16.8, 16.8, 16.7ms였다. 네 번 모두 최장 16.8ms였다. 전체 게임의 진입 시간은 기기·네트워크와 다른 장면 자산의 영향을 받는다.

## 재생성과 확인

저장소 루트에서 실행한다.

```sh
node assets/models/gyeongbu-fixtures/split.mjs
node assets/models/gyeongbu-fixtures/check.mjs
```

분할 스크립트는 glTF Transform으로 원본의 이름별 메시를 추출하고, 파일을 다시 열어 정점 속성·인덱스·계층 변환이 원본과 같은지 전수 검사한다. meshoptimizer로 만든 원거리 메시를 센티미터 단위 좌표와 색상으로 저장한다. 게임 검사는 첫 진입, 등진 진열대, 층 변경, 원거리 전환, 재접근, 전송 실패 후 복구를 확인한다.
