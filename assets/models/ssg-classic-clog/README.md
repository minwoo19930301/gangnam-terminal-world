# 신세계 강남점 8층 크록스

크록스 공식 매장 안내와 신세계 층별 안내에서 강남점 8층 입점을 확인했다. 클래식 클로그의 둥근 앞코, 열린 뒤축, 한 짝에 13개인 통기구, 양쪽 피벗으로 연결된 스트랩을 모델링했다. 진열대에는 17짝을 놓았고, 지비츠 카운터에는 꽃·별·체리 모양의 견본을 담았다. 진열 색상과 가구 배치는 게임용 구성이다.
