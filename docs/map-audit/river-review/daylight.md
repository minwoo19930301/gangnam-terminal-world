# 반포의 하늘

기본 모드는 서울 실시간이다. 브라우저의 UTC 시각과 프로젝트 원점인 북위 37.5050371도, 동경 127.0049222도로 태양 고도와 방향을 계산한다. 수평선 가까이의 빛은 태양 방향에 모이고, 태양이 지평선 아래 3도에 이르면 게임 안 야간 조명이 켜진다. 표시 시각은 접속 지역과 관계없이 서울 시각이다.

화면의 시간 선택기로 아침·낮·노을·밤을 미리 볼 수 있다. 아침은 그날 일출 14분 후, 노을은 일몰 14분 전이다. 낮과 밤은 각각 12시 30분과 22시다. N은 낮·밤 전환, Shift+N은 서울 실시간으로 복귀한다. 실시간 모드에서는 탭으로 돌아오면 현재 시각으로 갱신한다.

태양 위치와 지평선 보정은 [NOAA 계산 설명](https://gml.noaa.gov/grad/solcalc/calcdetails.html)을 참고했다. 2026년 11월 26일 반포 계산값은 일출 07:22, 일몰 17:15이며 같은 날 서울 예보는 07:23, 17:16이다. 서울 예보 지점과 반포의 위치, 실제 기상과 지형에 따라 관측 시각은 달라진다. [기상청 서울 예보](https://www.weather.go.kr/w/repositary/xml/fct/rpt_wid_day_202611251700_109.pdf)

`node tests/daylight.mjs --gpu`는 기상청 시각, 하지·동지 태양 높이, 다른 시간대에서의 서울 시각, 아침·노을의 방향, 야간 조명과 시각 복귀를 확인한다.
