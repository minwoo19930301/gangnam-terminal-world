# 터미널 주변 좌표·지표 높이 재점검

2026년 11월 25일 [기준점 목록](controls.csv)의 197개 노드를 OpenStreetMap 공식 API에서 모두 다시 읽었다. 모델의 센티미터 단위 x/z를 위경도로 되돌렸을 때 원본 노드까지 수평 거리는 평균 3.77 mm, 최대 6.94 mm였다. 지도 데이터의 변환·반올림을 확인한 수치이며 출입구나 신호기 실물의 측량 정확도는 별도로 확인해야 한다. [OpenStreetMap API와 데이터 저작권](https://www.openstreetmap.org/copyright)

## 서울시 원본 표고점

서울열린데이터광장의 ‘서울시 등고선.zip’에서 2023년 기준 1:5,000 수치지형도 표고점 레이어 N3P_F002를 직접 읽었다. 단지와 경계도로를 포함하는 로컬 범위 −200 ≤ x ≤ 530, −250 ≤ z ≤ 340 안에 있는 44개 점을 모두 포함했다. EPSG:5174에서 WGS84로 변환한 **표고점 자체의 위치**에서 HEIGHT와 각 표면을 대조했다. F002는 타일 생성에도 쓰인 원자료이므로 이 비교는 가공 중 높이가 얼마나 달라졌는지를 보여 준다. 수직 기준면과 각 점이 대표하는 구조물의 층위는 이 비교에서 추가로 확정하지 않았다. [서울시 공식 배포 페이지](https://data.seoul.go.kr/dataList/OA-22241/F/1/datasetView.do)

예를 들어 삼호가든사거리 신호 노드에서 약 4.45 m 떨어진 F002 표고점의 HEIGHT는 17.60 m였다. 그 **표고점 위치**의 원타일은 17.53 m, 격자와 모델 지형은 17.22 m였다. 1·7·8번 출구에서 조사 범위 내 가장 가까운 표고점은 각각 약 78.36 m, 36.41 m, 31.86 m 떨어져 있다. 이 표고점 값을 출구 문턱 높이로 대입하지 않았다.

가장 큰 F002–모델 지형 차이는 UFID `100037705091F0021dcba98328fd54111` (북위 37.5037512°, 동경 127.0063687°)에서 확인했다. F002 19.56 m, 원타일 19.35 m, 25m 격자 18.77 m, 모델 지형 6.95 m다. 이 지점은 모델이 별도 단지 구조물을 놓기 위해 기초 기준면을 낮춘 곳이다.

## 재현

저장소 루트에서 실행한다. Node.js와 uv를 사용하며, 실행 결과는 표준 출력으로 나온다. 서울시 ZIP과 고정 타일은 사용자 캐시에 보관한다. OSM은 매 실행 시 조회하므로 편집된 노드의 버전과 차이는 바뀔 수 있다. 기존 ZIP이 있으면 마지막 인자로 경로를 지정한다.

```sh
uv run --with numpy --with pillow --with shapely --with pyproj --with pyshp python tools/check_network_elevations.py
```

서울시 ZIP의 SHA-256은 `4fbe3c7e061b5974e7403ec116855304ed8ae321eebcc0d12c31ca8fb7be30bf`다. 타일은 `ede67d9f3909395d346ab67e492d63fd10142d08` 리비전의 RGB와 유효성 마스크를 함께 사용했다. [검증 스크립트](../../../tools/check_network_elevations.py)
